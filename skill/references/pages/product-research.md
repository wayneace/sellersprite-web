# 选产品（product research）

## 1. 用途

按关键词/类目和一系列数值条件，从亚马逊商品库里筛出符合要求的商品：月销量、销售额、子体销量、增长率、BSR、变体、价格、Q&A、评分数、评分、留评率、FBA 运费、毛利率、LQS、重量、买家运费、卖家数量等。

- 适合：按销量/价格/评分/卖家类型筛品；类目 + 价格带选品；竞品 ASIN 反查同款；导出候选清单。
- 不适合：看单个商品的流量结构（用流量类页面）；看市场集中度/新品占比（用「选市场」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/product-research`
- 导航：工作台「产品」→ 大数据选品 → **选产品**；页面子导航第二项也是「选产品」。
- 查询后 URL 带完整条件，例如
  `?market=US&page=1&size=60&symbolFlag=true&monthName=bsr_sales_nearly&selectType=2&filterSub=false&weightUnit=g&order[field]=amz_unit&order[desc]=true&productTags=[]&nodeIdPaths=[]&sellerTypes=[]&eligibility=[]&pkgDimensionTypeList=[]&sellerNationList=[]&keywords=yoga%20mat&minSales=100&lowPrice=N&salesGrowthType=30d&video=`
- 结果页标题变为「查询结果|选产品|卖家精灵」。

## 3. 站点选择

- 站点是一排按钮（美国站/日本站/英国站/德国站/法国站/意大利/西班牙/加拿大/印度站/墨西哥），不是下拉。
- US 用 USD（页面显示 `$`），CA 用 CAD（页面显示 `C$`）；价格、销售额、FBA 运费、买家运费等货币字段随站点。
- 切换站点后会重新查询；必须重新读 total、币种和表头。详见 [sites.md](../sites.md)。
- 本页做过 CA 代表查询（`market=CA`、`yoga mat`、月销量 ≥100），记录见 `docs/verification/sites.md`。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库 / 自定义品类。
2. **顶部条件区**：电商平台（亚马逊/TikTok）、站点按钮、月份按钮、推荐模式/我的模式、选择类目、只看该子类目排名。
3. **筛选面板**（可「隐藏过滤条件」）：销售表现、产品信息、上架时间、包装、买家运费、卖家、品牌、关键词等分组。
4. **结果工具栏**：复制 ASIN、自定义品类、加入产品库、导出/导出明细、搜索结果数、展示所有变体、列表/大图、自定义列。
5. **结果表**与**分页区**。

## 5. 必填输入与可选筛选

- 关键词不是必填；空着可以浏览全库（配合类目/销量条件）。
- 关键词输入在「包含关键词」，支持逗号分隔多个；「排除关键词」排除标题中的词。
- 关键词匹配方式（radio，页面可见标签）：
  - **模糊匹配**（默认，URL `selectType=2`）
  - **词组匹配**（`selectType=4`）
  - **精准匹配**（`selectType=3`）
  - **这不是月份模式**；月份由上面的月份按钮控制（默认「最近30天」= `bsr_sales_nearly`，或选自然月）。
- 变体范围：「展示所有变体」复选框。旧验证（同条件同月份、销售额 [0,587]）唯一畅销变体 1,994 行 vs 所有变体 5,358 行，差很多。旧知识说 URL `symbolFlag=true` 对应唯一畅销变体、复选框与表单值取反；但 2026-11-12 冷启动实测取消勾选后 URL 出现 `symbolFlag=false`，与旧映射不一致。**以页面复选框的回显为准，不要只凭 URL 判断变体口径**；改口径用复选框并重新查询。
- 主要筛选组（页面可见标签）：
  - 销售表现：月销量、月销售额、子体销量、月销量环比增长率、BSR、小类BSR、BSR增长数、BSR增长率。
  - 产品信息：变体数、价格、Q&A、评分数、月评新增、评分值、留评率、FBA运费、毛利率、上架时间、LQS、包装重量、包装尺寸、买家运费、商品资格（低价商品）、卖家数量。
  - 卖家与品牌：卖家所属地、包含品牌/排除品牌、包含卖家/排除卖家、排除关键词、包含关键词。
  - 勾选/单选：配送方式（AMZ/FBA/FBM）、主图视频（不限/含视频/不含视频）、商品标识（Best Seller/Amazon's Choice/New Release/A+/不含A+）。
- 类目树可以多选；「只看该子类目排名」在选中末级子类后才可用。
- 推荐模式是快捷模板（低价长尾选品、研发新品榜、潜力单变体、销量飙升榜等），会改写筛选条件；用了它要重新核对回显。
- 数值区间是闭区间；货币字段随站点。

## 6. 操作流程

1. 打开页面，确认站点、月份。
2. 填关键词（可空）和需要的数值/勾选条件；类目用「选择一个或多个类目和子类目」。
3. 点筛选面板底部的「开始筛选」（不是「立即查询」）；等待结果工具栏出现「搜索结果数」和表格。
4. 动作后重新 `observe`；「开始筛选」点击成功不等于查询生效。
5. 结果工具栏可以改排序、每页条数、展示所有变体；每次改动都会再查一次页面，改完重新读表。
6. 用 `<skill-dir>/scripts/read-table.js` 读表；本页结果也是 div 版 Element UI 表格。

## 7. 结果表关键列

实测表头（2026-11-12，US，关键词 `yoga mat`，月销量 ≥100）：

`#`、`产品信息`、`数据解释`、`大类BSR`、`销量趋势(父)`、`销量趋势(子)`、`销量(父)`、`增长率`、`销售额`、`子体销量`、`子体销售额`、`变体数`、`价格`、`Q&A`、`评分数`、`月新增`、`评分`、`留评率`、`FBA`、`毛利率`、`上架时间`、`配送`、`买家运费`、`操作`。

- 产品信息列内含标题、ASIN、品牌、类目、卖家、卖家所属地、Coupon、尺寸/重量等；「自定义列」可增减列。
- 字段易错点：
  - `销量(父)` 是父体级销量，包含父体下所有卖家；`子体销量` 是子体口径，不能直接对比或相加。
  - 评分数不是文字评论条数；留评率 = 月新增评分数 / 月销量。
  - 毛利率是扣亚马逊佣金和 FBA 后的估算，不是采购毛利。
  - 上架时间是 Keepa 首次见价/BSR 的日期，不是精确上架日。
- 完整口径见 [fields.md](../fields.md)。

## 8. 排序、分页、每页条数

- 默认排序「子体销量 / 降序」（URL `order[field]=amz_unit&order[desc]=true`）。
- 排序控件在结果区工具栏（「--排序方式--」+ 升降序 + 确定）。它可能被 bsk 控制浮层或 tooltip 遮挡：点不开时先 `scroll-to`/重新 `observe`，必要时 `focus` 后按 `Enter`，不要连点；改完核对页面回显。
- 每页条数页面只提供 **60 / 100**；其他值不要手改 URL。
- 超过 100 条/页时页面可能返回 `total: null`，容易误判成无结果；用 60 或 100。
- 前端只暴露前 **5000** 条匹配；超过后翻页会截断。页面标题区显示「搜索结果数: 5,000+」，分页组件实测 total=2000（US / yoga mat / minSales=100 / 60 条）。两者口径不同，报告两个都写。
- 翻页、改每页条数、改排序都会触发页面自己的查询；翻页后重新读表。

## 9. 导出

1. 先查询出结果（导出按钮只在有结果后可用）。
2. 点「导出」（不要误点「导出明细」）；只提交一次。
3. 页面提示「数据导出中/导出成功/前往我的导出」后，去右上「我的导出」看任务。
4. 文件出现后用 `bsk download` 保存到用户指定路径。
5. 本页验证**没有提交导出任务**，只确认了按钮和「我的导出」入口存在。

## 10. 空态与页面坑

- 条件过严时显示「很抱歉，暂无结果！」，建议：重新选择类目；重新选择过滤条件（先重置条件）；或使用系统推荐选品模式。
- 空态文本不在 `.el-table__empty-text` 里：`read-table.js` 会返回 `total=0`、`rowCount=0`、`empty=false`。判断空结果看 `total` 和正文。
- 「开始筛选」在筛选面板底部；页面很长，按钮可能在视口外，先 `scroll-to` 或确认可见再点。
- 推荐模式 / 展示所有变体 / 排序 / 每页条数都会触发额外查询，注意查询次数。
- 切换站点或月份后必须重新点「开始筛选」，否则结果还是旧条件。

## 11. 验证清单

- [ ] URL 是 `/v3/product-research` 且带本次条件（keywords、minSales、monthName、size、page）。
- [ ] 站点和币种一致（US/USD 或 CA/CAD）。
- [ ] 月份是页面按钮显示的值（默认「最近30天」）。
- [ ] 关键词匹配方式回显正确（模糊/词组/精准）。
- [ ] 变体口径（展示所有变体）与报告一致。
- [ ] `total`（分页组件）+「搜索结果数」都记录。
- [ ] 实际读取行数、当前页、每页条数。
- [ ] 表头与文档一致；用了「自定义列」要说明。

## 12. 典型配方

1. **关键词 + 销量筛品**：包含关键词 `yoga mat` → 月销量 ≥100 → 最近30天 → 开始筛选 → 读前 60 行。
2. **类目 + 价格带**：选择类目（可多选末级）→ 价格 10–30 → 评分 ≥4.3 → BSR ≤50000 → 开始筛选。
3. **竞品 ASIN 反查同款**：把 ASIN 填进包含关键词（或类目定位）→ 再用品牌/卖家/价格条件收窄。
4. **导出候选清单**：先用页面总数确认量级（不建 CLI），再点「导出」→ 我的导出 → `bsk download`。
