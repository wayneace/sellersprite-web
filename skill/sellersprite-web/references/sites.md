# 站点选择（sites）

卖家精灵同一套工具切换站点后，查询条件和页面结构不变，**货币、部分单位和结果集**会变。报告必须带站点。

## US

- 站点显示：查询栏最左侧「美国站」+ 美国国旗。
- 货币：美元 **USD**，价格、销售额、FBA 费用、PPC 竞价等货币字段都是 USD。
- 重量/体积单位以页面标签为准；product-research 的包装重量实测以 **g** 为单位（URL `weightUnit=g`）。FBA 费用按站点规则计算。本版未逐项验证其他页面的重量/体积单位。
- 数据月份：页面默认「最近30天」，也可以选自然月；「最近30天」不是自然月。
- 本版在 US 做完整验证；每页实际验证状态以 `docs/verification/` 的记录为准，没有记录的页面按未验证对待。

## CA

- 站点显示：选产品是「加拿大」按钮；带下拉的页面选项为「加拿大」（下拉里可能显示为「加拿大站」）。
- 货币：加元 **CAD**；**页面实际显示 `C$`**（2026-11-12 选产品实测：销售额 `C$62,168`、价格 `C$25.99`、FBA `C$12.04`），不是美元 `$`。
- 重量/体积单位以页面标签为准；product-research 实测同样使用 **g**（`weightUnit=g`）。FBA 费用按加拿大站规则计算；本版未逐项验证其他页面的重量/体积单位。
- 本版抽查范围：
  - **选产品**：完成一次 CA 代表查询（`yoga mat`、月销量 ≥100、最近30天），记录 C$ 与表头。
  - **竞品分析 / 关键词挖掘 / 关键词反查 / 查流量来源**：只确认站点控件存在且含「加拿大」选项，未逐页跑查询。
  - **关键词选品**：页面有「加拿大」按钮，未跑 CA 查询。
  - 页面文档里没有 CA 验证记录的，按未验证对待。
- 2026-11-14 新增页面只做站点控件检查：
  - 选市场、ABA数据选品、产品库、流量词对比、拓展流量词、关键词转化率、关键词词库、实时查竞价：确认控件含「加拿大」，未选择、未查询。
  - 广告洞察、关联流量、出单词反查、AI评论分析2.0、销量预测、利润计算器、批量下载图片、竞品运营拆解、市场洞察、AI-找竞品、Listing诊断、AI-拓产品：确认控件含「加拿大」，未选择、未查询/生成/计算/下载；没有生成 CA AI 报告。
  - 关键词需求洞察：页面固定美国站，没有站点控件；CA 不可选、未验证。

## 切换与核对

1. 站点选择器在**每个工具的查询栏最左侧**（日期范围「最近30天」左边），不是浏览器地址里的参数。
2. 切换站点后页面会重新查询或清空结果；必须重新点「立即查询」，不能沿用切换前的结果。
3. 切换后核对四件事：国家文案、币种符号（US 是 `$`，CA 是 `C$`）、总数、表头是否一致。
4. 站点选择会跨页面保留（实测在选产品切到加拿大后，竞品分析的选择器也显示加拿大）；每次查询前仍要重新确认，避免误把 CA 数据当 US。
5. 报告里写「US / 美国站」或「CA / 加拿大站」；同一份报告不要混用两个站点的数据。
6. 不猜测未验证站点的编码、币种或单位；页面显示什么就写什么。
