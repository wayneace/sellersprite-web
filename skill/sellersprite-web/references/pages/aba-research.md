# ABA 数据选品（ABA research）

## 1. 用途

基于亚马逊 Brand Analytics（ABA）搜索频率排名，按周或按月筛选搜索词，观察搜索量、排名变化、点击/转化集中度、PPC 竞价和点击前三 ASIN/品牌，用真实搜索行为找潜力词与市场。

- 适合：找近期搜索排名上升的词；看一个关键词的点击/转化集中度；按周/月追踪需求变化；从 ASIN/关键词出发扩展 ABA 词。
- 不适合：按类目看市场规模（用「选市场」）；按销量/价格筛具体商品（用「选产品」）；反查单个 ASIN 的全部流量词（用「关键词反查」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/aba-research`
- 导航：工作台「产品」→ 大数据选品 → **ABA数据选品**。
- 查询后仍在 `/v3/aba-research`，查询条件主要保存在页面状态和 URL 参数中；报告以页面回显为准。

## 3. 站点选择

- 查询栏最左侧是国家/站点下拉（默认「美国站」），可切日本站、英国站、德国站、法国站、意大利、西班牙、加拿大、印度站、墨西哥、巴西站、澳洲站、阿联酋、沙特站。
- US 用 USD；CA 用 CAD。切换站点后重新查询，并核对币种。
- 本页 US 已完整验证；CA 只确认站点控件，未验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 NEW / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库 / 自定义品类。
2. **规则提示**：亚马逊 2023-05-22 更新搜索频率排名规则——同一时间范围内搜索频率相同的词显示相同排名，并按字母数字顺序排序。
3. **查询栏**：站点下拉、按周/按月、周/月选择器、输入框（父/子体 ASIN 或关键词）、立即查询、查询历史、示例词/示例 ASIN。
4. **快捷市场预设**：热门市场 / 异动市场 / 持续增长市场 / 快速飙升市场 / 潜力市场 / 长尾市场。
5. **搜索结果过滤**面板：增长率、排名、搜索量、点击/转化、竞价、词长等区间；开始筛选、重置条件。
6. **结果区**：搜索结果数、表格、分页。

## 5. 必填输入与可选筛选

- 输入：父/子体 ASIN 或关键词，例如 `B07Z82895W`、`iphone charger`、`screen protector`。
- 时间粒度：按周 / 按月；周选择器默认显示最近一周（本次为 `2026第45周(11/01~11/07)`）。
- 站点：默认美国站。
- 快捷预设：点一个预设会直接改变筛选条件并查询；预设和手动过滤面板叠加时，以页面回显为准。
- 过滤面板常见条件：搜索增长率、ABA 排名、周/月搜索量、点击共享、转化共享、PPC 竞价、单词个数、包含/排除关键词、类目等。
- **「开始筛选」是过滤面板的第二次查询**：改完条件必须再点一次；只改表单不会刷新结果。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/aba-research" --json`；确认标题「ABA数据选品」、站点是美国站。
2. 需要时切「按周/按月」和具体周/月；默认保持最近一周。
3. 在输入框填关键词或 ASIN，点「立即查询」；等结果表出现。
4. 需要收窄时，在「搜索结果过滤」里填条件，再点「开始筛选」；确认总数变化。
5. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`，能读 `total/pageSize/currentPage`）。
6. 动作后重新 `bsk sync` 再读；不要用点击成功代替结果刷新。

## 7. 结果表关键列

实测表头（2026-11-14，US，关键词 `screen protector`，2026 第45周）：

`#`、`关键词 数据解释`、`周排名/搜索趋势`、`周搜索量`、`现排名`、`历史排名`、`排名变化`、`排名变化率`、`展示量 点击量`、`PPC竞价 精准`、`SPR`、`标题 密度`、`点击前三ASIN`、`点击前三品牌`、`操作`。

`read-table.js` 返回的 item 关键字段：

- `keyword` / `keywordCn`：英文/中文关键词。
- `searches`：周搜索量（按月查询时是月搜索量）。
- `searchRank`：当前 ABA 排名；`w1SearchRank` / `w4SearchRank` / `w12SearchRank`：上周/4周前/12周前排名。
- `searchRankGrowthValue` / `searchRankGrowthRate`：排名变化值与变化率；负数表示排名下降（数值变小通常代表上升，按页面显示为准）。
- `impressions` / `clicks`：展示量/点击量；`top3ClickRate` / `top3sumConversionRate`：点击前三 ASIN 的点击/转化集中度。
- `clickShareRate` / `cvsShareRate`：点击共享/转化共享。
- `purchaseRate` / `purchases`：购买率/购买量。
- `cprExact`：精准匹配 CPR；`titleDensityExact`：标题密度。
- `tableHistoryDate`：数据周（如 `ara_20261107`）；`website`：站点域名；`marketId`。
- PPC 竞价字段可能为 `--`（本次首行就是 `-- -- --`），不要补造。

## 8. 排序、分页、每页条数

- 默认排序以页面下拉/表头为准；本次未改排序。
- 每页 **50** 条。
- 实测总数 **4,482**，第 1 页 **50** 行，`pageSize=50`、`currentPage=1`。
- 分页用 `read-table.js` 的 `total/pageSize/currentPage`；翻页后重新读表。
- 「搜索结果数」和分页 total 可能同时出现，两个都记录。

## 9. 导出

- 结果工具栏有「导出」按钮（本次 VOM 可见）。
- 本次验证**没有点击导出**。导出是异步任务：先确认筛选条件和总数，单独征得用户同意，只提交一次，到「我的导出」看状态。

## 10. 空态与页面坑

- 空态原文：**「主人-暂无相关数据哦!」**；实测用关键词 `zzzzzzzzzzzzzz` 查询后 `rowCount=0`、`total=0`、`empty=true`。
- 查询输入是自定义 combobox：`bsk read` 能看到 `input[placeholder^="输入父"]` 的 ref；直接点整个 combobox 可能只展开站点/日期面板。
- 站点、按周/按月、周/月选择器都在同一个查询栏；改时间或站点后要重新查询。
- 预设按钮和过滤面板都会改变结果；不要把预设名当筛选条件的完整回显。
- 过滤条件不保证全部写入 URL；复制 URL 不一定能复现筛选。
- ABA 同频词会显示相同排名并按字母排序，不要用排名相同判断数据错误。

## 12. 典型配方

1. **找上升词**：输入种子词或示例 ASIN → 按周 → 立即查询 → 过滤面板设「搜索增长率 ≥ 10%」→ 开始筛选 → 按增长率排序读前 50。
2. **看竞争集中度**：看 `top3ClickRate` / `top3sumConversionRate`；集中度高说明头部 ASIN 吃掉大部分点击/转化。
3. **找低竞价词**：过滤面板设 PPC 竞价上限 → 开始筛选 → 结合搜索量和 CPR 判断投放价值。
4. **从 ASIN 扩展**：输入父/子体 ASIN → 看该 ASIN 相关的 ABA 搜索词；再拿词去「关键词反查」或「选产品」。
5. **看长期需求**：切「按月」→ 选月份 → 重新查询；不要和周数据混在一起比较。
