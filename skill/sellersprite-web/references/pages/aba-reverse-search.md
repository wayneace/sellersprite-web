# 出单词反查（ABA reverse search）

## 1. 用途

输入单个 ASIN，反查该 ASIN 进入过哪些 ABA 关键词的点击前 3 名，以及这些词带来的搜索量、点击占比和转化占比。

- 适合：找某个 ASIN 的出单词、判断哪些词可能带来订单、看关键词的点击/转化集中度。
- 不适合：查广告投放架构（用「广告洞察」）；查关联流量（用「关联流量」）；查自然/广告流量来源占比（用「查流量来源」）。
- 数据来源：亚马逊后台品牌分析（ABA）的关键词搜索报告；只有 ASIN 进入某关键词点击排名前 3 时，该词才会被收录。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v2/aba/reverse/search`
- 查询后 URL 形如：
  `https://www.sellersprite.com/v2/aba/reverse/search?station=US&table=ara_20261107&asin=&order.field=searchRank&order.desc=false&conversionType=&loadVariations=false&reverseType=W&monthlyTable=ara_202610&textareaValue=<ASIN>`
- 导航：工作台「运营推广」→ **出单词反查**。
- 这是 **v2 页面**，布局和控件与 v3 页面不同。

## 3. 站点选择

- 表单左侧站点按钮，默认「美国」；本页结果表没有价格列，币种未验证。
- 站点菜单实测包含：美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度、墨西哥、巴西站、澳洲站。

## 5. 必填输入与可选筛选

- **ASIN**：必填，单个 ASIN。页面是 v2 自定义输入，不是标准 `input` textbox；点示例 ASIN 会填入并自动查询。
- **站点**：默认美国。
- **数据粒度**：`每周`；周选择 `2026第45周(11/01~11/07)`。
- **包含所有变体**：复选框，默认不勾选；勾选后结果范围变化，需重新查询。
- **按效果筛选**：先选择转化效果后才可用；本次未使用。
- **排序**：表头可排序（排名、周变化量、周变化率、ABA集中度等）；本次保持默认。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v2/aba/reverse/search" --json`；确认标题含「出单词反查」、站点是美国。
2. 点示例 ASIN `B00000JBNX`；页面自动填入并查询，不需要再点 `立即查询`。
3. 若输入框 `bsk fill` 超时：先 `bsk sync` 看是否已写入；没有写入就点示例链接，不重放同一动作。
4. 等 `搜索结果数` 从空/0 变成实际数字，再读表。
5. 用 `bsk extract table --json` 读表；本页是 HTML 表格，extract 可直接读列和行。
6. 本次读到 50 行；页面有 `加载全部` 按钮，未点击，不把 50 行当全部 63 条。
7. 不要点 `导出Excel`、`加入词库`、`全部加入词库`、`关键词对比`；本次只读。
8. 结束 `bsk close`。

## 10. 空态与页面坑

- **v2 自定义输入**：ASIN 输入不是标准 textbox；`bsk fill` 可能超时。先 `bsk sync` 确认是否已写入；没写入就点示例链接，不重放。
- **示例自动查询**：点示例 ASIN 会直接查询；不要再点 `立即查询`，避免重复查询。
- **63 不是 50**：`搜索结果数` 是 63，当前 DOM 只加载 50 行；需要全部时点一次 `加载全部`，本次未点。
- **HTML 表格**：`bsk extract table` 可用；最左空列会显示为 `Column 1`，不要把它当业务列。
- **首行关键词中英混排**：extract 的 `关键词` 是 `calculator\n计算器`；报告写英文词，中文是页面翻译。
- **排名趋势是多列**：`排名趋势` 下有排名/周变化量/周变化率三个子列，不要只读一个。
- **周数据**：数据周是页面周选择器的值（本次 2026第45周 11/01~11/07），不要按系统日期猜。
- **空态未验证**：本次未触发空态，不要猜具体文案。
- **隐私**：页面可能显示卖家/品牌等公开信息；报告不需要记录卖家联系方式。

## 12. 典型配方

1. **找 ASIN 的出单词**：输入 ASIN → 读 `搜索结果数` → extract 表 → 按周搜索量/转化效果排序。
2. **找高转化词**：看 `转化效果=转化优质词` + `转化占比` 高的行；再拿去做关键词反查/广告洞察。
3. **看排名变化**：读 `排名趋势` 的排名/周变化量/周变化率，找近期上升词。
4. **看集中度**：读 `点击占比`、`转化占比`、`ABA集中度`，判断头部 ASIN 是否垄断。
5. **后续分析**：把词拿到「关键词挖掘」拓词，或「关键词转化率」看 CPA/ACOS；本页不写词库、不导出。
