# 产品库（product store）

## 1. 用途

管理账号里的产品库：按产品库名称、标签、所属站点查看已收集的产品集合，并作为后续广告投放/否定或选品分析的输入。

- 适合：查看自己有哪些产品库；按标签/名称定位某个库；确认库的站点、产品数量、创建/更新时间。
- 不适合：直接在这里新建/删除库（本版只读，不执行写操作）；按 ASIN 查商品详情（用「选产品」或「竞品分析」）；查关键词（用关键词优化相关页面）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/product-store`
- 导航：工作台「产品」→ 大数据选品 → **产品库**。
- 本页是账号内的个人数据页，不提供公开市场查询；URL 不携带库名/标签条件。

## 3. 站点选择

- 查询栏最左侧有站点下拉（默认「所有站点」），列表每行还有「所属站点」列。
- US 库显示「美国站」；CA 库显示「加拿大站」。本页 US 已读；CA 只确认站点控件，未验证 CA 库的数据/币种。
- 切站点/标签后点「查询」再读列表。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 NEW / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库 / 自定义品类。
2. **查询栏**：站点下拉、标签下拉、输入框「请输入标签或产品库名称」、查询、新建产品库、标签管理。
3. **批量工具栏**：批量删除、批量投放广告、编辑标签（本版不点）。
4. **列表**：`#`、产品库名称、标签、所属站点、产品数量、创建时间、更新时间、操作。
5. **分页**：底部有页码/跳转/每页条数（本次 total 8、pageSize 50、currentPage 1）。

## 5. 必填输入与可选筛选

- 查看列表不要求输入；打开页面即可看到当前账号的产品库。
- 可选筛选：
  - 站点：所有站点 / 美国站 / 加拿大站等。
  - 标签：请选择标签。
  - 名称/标签关键词：输入「标签或产品库名称」后点「查询」。
  - 排序：产品库名称、降序/升序（页面下拉）。
- 「新建产品库」「标签管理」「批量删除」「批量投放广告」「编辑标签」都是写操作；本版不执行。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/product-store" --json`；确认标题「产品库」和账号已登录。
2. 需要时选站点/标签，填名称关键词，点「查询」。
3. 用 `<skill-dir>/scripts/read-table.js` 读取列表；只取列名、是否非空、total/pagination，不输出库名/标签/产品数量。
4. 翻页后重新读表；不要点新建、删除、批量投放。
5. 结束 `bsk close`。

## 7. 结果列

实测表头（2026-11-14，US，默认「所有站点」）：

`#`、`产品库名称`、`标签`、`所属站点`、`产品数量`、`创建时间`、`更新时间`、`操作`。

- `产品库名称` / `标签` 是账号个人数据；报告里用 `<library-name>` / `<tag>` 代替。
- `产品数量` 是该库收集的商品数，不是市场销量；不要和「选产品」的销量字段混淆。
- `操作` 列提供库内操作入口（本版未展开）。

## 8. 排序、分页、每页条数

- 默认排序：产品库名称降序（页面下拉显示「产品库名称 / 降序」）。
- 每页 **50** 条。
- 实测 total **8**（库数量）、`pageSize=50`、`currentPage=1`、`rowCount=8`。
- 列表较短时也可能不显示分页；以 `read-table.js` 的 `total/pageSize/currentPage` 为准。

## 9. 导出

- 本页没有导出按钮；产品库数据不通过本页导出。
- 需要导出库内产品时，用库的「操作」入口或对应的广告/选品页面；本版未展开。

## 10. 空态与页面坑

- 搜索不存在的库名时，页面显示 **「您还未创建产品库~」** 及安装插件/收集产品的提示；即使账号里实际有库，也会出现这段空态文案。
- 此时 `read-table.js` 可能出现 `rowCount=0` 但 `total` 仍保留上一轮的库数量（本次为 8），`empty=false`；**不要只凭 total 判断有结果**，要同时看 `rowCount` 和页面正文。
- 产品库名称/标签是个人数据；验证记录、报告和截图都不要带出。
- 「新建产品库」「批量删除」「批量投放广告」有副作用；本版只读，不点击。
- 库的「产品数量」是收集数，不是销量/销售额；不要当作市场指标。

## 12. 典型配方

1. **按名称找库**：输入库名关键词 → 查询 → 读列表 → 用「操作」进入库（本版未展开）。
2. **按标签筛选**：标签下拉选标签 → 查询 → 读列表。
3. **按站点看库**：站点下拉切美国站/加拿大站 → 查询 → 核对「所属站点」列。
4. **只读巡检**：打开页面读 total/columns；不执行任何写操作。
5. **后续使用**：产品库可作为优麦云广告投放/否定的输入；本 skill 不执行广告写操作。
