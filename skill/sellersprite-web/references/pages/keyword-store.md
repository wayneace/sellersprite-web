# 关键词词库（keyword store）

## 1. 用途

管理账号里的关键词词库：从「关键词挖掘」「关键词反查」「流量词对比」等页面把词加入词库，用标签/站点/词库名查询，作为后续广告投放、否定或选词分析的输入。

- 适合：查看自己有哪些词库；按标签/名称/关键词定位词库；确认词库的站点、关键词数量、创建/更新时间。
- 不适合：在词库页新建/删除词库（本版只读，不执行写操作）；拓词（用「关键词挖掘」）；查某个 ASIN 的流量词（用「关键词反查」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/keyword-store`
- 导航：工作台「产品」→ 关键词优化 → **关键词词库**。
- 本页是账号内的个人数据页，URL 不携带词库名/标签条件；查询条件在页面表单里。

## 3. 站点选择

- 查询栏最左侧有站点下拉（默认「所有站点」）；列表每行有「所属站点」列。
- US 词库显示「美国站」；CA 词库显示「加拿大站」。本页 US 已读；CA 只确认站点控件，未验证 CA 词库。
- 切站点/标签后点「查询」再读列表。

## 4. 页面结构

1. **子导航**：关键词挖掘 / 关键词反查 / 流量词对比 / 拓展流量词 / 关键词转化率 / 实时查竞价 / 关键词收录 / 关键词词库。
2. **查询栏**：站点下拉、标签下拉、输入框「请输入标签或词库名称」、输入框「包含关键词」、查询、新建词库、标签管理。
3. **列表**：`#`、词库名称、标签、所属站点、关键词数量、创建时间、更新时间、操作。
4. **分页**：有数据时显示在底部；本次账号词库为空，未显示分页。
5. **结果工具栏/批量操作**：批量删除、批量投放广告、编辑标签（本版不点）。

## 5. 必填输入与可选筛选

- 查看列表不要求输入；打开页面即可看到当前账号的词库。
- 可选筛选：
  - 站点：所有站点 / 美国站 / 加拿大站等。
  - 标签：请选择标签。
  - 词库名称/标签关键词：输入后点「查询」。
  - 包含关键词：输入一个词，查询包含该词的词库。
- 「新建词库」「标签管理」「批量删除」「批量投放广告」「编辑标签」都是写操作；本版不执行。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/keyword-store" --json`；确认标题「关键词词库」和账号已登录。
2. 需要时选站点/标签，填词库名或包含关键词，点「查询」。
3. 用 `<skill-dir>/scripts/read-table.js` 读取列表；只取列名、是否非空、total/pagination，不输出词库名/标签/关键词内容。
4. 列表为空时读取页面提示（见第 10 节），不要沿用上一轮数据。
5. 结束 `bsk close`。

## 7. 结果列

实测表头（2026-11-14，US，默认「所有站点」）：

`#`、`词库名称`、`标签`、`所属站点`、`关键词数量`、`创建时间`、`更新时间`、`操作`。

- `词库名称` / `标签` / `包含关键词` 是账号个人数据；报告里用 `<library-name>` / `<tag>` / `<keyword>` 代替。
- `关键词数量` 是该库的词数，不是搜索量/销量。
- `操作` 列提供库内操作入口（本版未展开）。

## 8. 排序、分页、每页条数

- 默认排序以页面为准；本页未显示排序下拉。
- 每页条数：有数据时按页面分页；本次账号词库为空，`read-table.js` 返回 `pageSize=50`。
- 实测 `rowCount=0`、`total=0`、`currentPage=1`。
- 列表为空时可能不显示分页；以 `rowCount/total` 和页面提示为准。

## 9. 导出

- 本页没有导出按钮；词库数据不通过本页导出。
- 需要导出词库时，用「操作」入口或对应的关键词页面；本版未展开。

## 10. 空态与页面坑

- 本次账号下词库列表为空（所有站点）：`read-table.js rowCount=0`、`total=0`、`currentPage=1`、`empty=false`、`emptyText=""`。
- 页面没有单独的「暂无数据」大文案，而是提示：
  - 「如果未能查找到对应的关键词词库，可能原因：」
  - 「1、您选择的站点国家与之前创建的词库不匹配」
  - 「2、您的词库名称输入有误」
  - 「3、您输入的查询关键词不在之前创建的词库中」
- `empty=false` 不代表有数据；空列表要同时看 `rowCount/total` 和页面提示。
- 词库名称/标签/关键词是个人数据；验证记录、报告和截图都不要带出。
- 「新建词库」「批量删除」「批量投放广告」有副作用；本版只读，不点击。

## 12. 典型配方

1. **按名称找库**：输入词库名关键词 → 查询 → 读列表 → 用「操作」进入库（本版未展开）。
2. **按标签筛选**：标签下拉选标签 → 查询 → 读列表。
3. **按包含词筛选**：在「包含关键词」输入一个词 → 查询 → 看哪些库包含它。
4. **按站点看库**：站点下拉切美国站/加拿大站 → 查询 → 核对「所属站点」列。
5. **后续使用**：词库可作为优麦云广告投放/否定的输入；本 skill 不执行广告写操作。
