# 拓展流量词（traffic extend）

## 1. 用途

一次性输入多个父/子体 ASIN，批量生成这些 ASIN 的流量词词库，并按流量占比、搜索量、购买量、竞争度等指标筛选；用来构建竞品词库、找共性词/差异词、挖掘长尾词。

- 适合：批量拓词；多个竞品合并去重；找红海共性词和蓝海差异词；从父/子体 ASIN 汇总变体词。
- 不适合：只对比 1 个自己的 ASIN + 少量竞品（用「流量词对比」）；查单个 ASIN 的完整流量词（用「关键词反查」）；查关键词转化率（用「关键词转化率」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/traffic/extend`
- 导航：工作台「产品」→ 关键词优化 → **拓展流量词**。
- 查询后 URL 形如
  `https://www.sellersprite.com/v3/traffic/extend/asin?q=B089K9L3VY,B07F8S18D5&marketId=1&date=`
- 结果页标题形如 `B089K9L3VY...|拓展流量词|卖家精灵`；`q` 是本次 ASIN 列表。

## 3. 站点选择

- 查询栏有站点下拉（默认「美国站」）和日期下拉（默认「最近30天」）。
- US 用 USD；CA 用 CAD。切换站点/日期后重新查询并核对币种。
- 本页 US 已完整验证；CA 只确认站点控件，未验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：关键词挖掘 / 关键词反查 / 流量词对比 / 拓展流量词 / 关键词转化率 / 实时查竞价 / 关键词收录 / 关键词词库。
2. **查询栏**：站点下拉、日期下拉、ASIN 输入区（最多20个）、清除、立即查询、查询历史、示例 ASIN。
3. **拓词方式弹窗**：选择「使用全部变体 / 使用畅销变体 / 使用当前变体」，每个选项显示预计流量词数。
4. **结果区**：`搜索结果过滤` 面板、`搜索结果数`、表格、分页。
5. **结果工具栏**：加入词库、全部加入词库、导出明细、导出。

## 5. 必填输入与可选筛选

- ASIN：至少 1 个，最多 **20** 个；多个以空格区分（页面示例也用逗号分隔，输入后组件会规范成 ASIN 列表）；支持从 txt/Excel 按列复制粘贴。
- 站点：默认美国站。
- 日期：默认最近30天。
- 拓词方式：全部变体 / 畅销变体 / 当前变体；不选就不出结果。
- 过滤面板常见条件：流量占比、ABA 周排名、月搜索量、月购买量、购买率、展示量、点击量、SPR、标题密度、商品数、需供比、广告竞品数、点击总占比、转化总占比、PPC 竞价。
- 改完过滤条件点「开始筛选」（结果区内的第二次查询）。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/traffic/extend" --json`；确认标题「拓展流量词」、站点是美国站。
2. 在 ASIN 输入区填 1–20 个父/子体 ASIN；需要重填先点「清除」。
3. 点「立即查询」；出现「选择拓词方式」弹窗时选一种：全部变体 / 畅销变体 / 当前变体。
4. 等结果页出现 `搜索结果数` 和表格；再读表。
5. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`，能读 `total/pageSize/currentPage`）。
6. 不要点「加入词库」「全部加入词库」「导出明细」「导出」；本次只读验证。
7. 结束 `bsk close`。

## 7. 结果表关键列

实测表头（2026-11-14，US，ASIN `B089K9L3VY B07F8S18D5`，选「全部变体」）：

`#`、`关键词 数据解释`、`内测版 流量占比`、`相关ASIN`、`月搜索趋势`、`ABA周排名`、`月搜索量 增长率`、`月购买量`、`展示量 点击量`、`SPR`、`标题 密度`、`需供比 商品数`、`广告 竞品数`、`ABA集中度`、`PPC竞价 精准`、`操作`。

`read-table.js` 返回的 item 关键字段：

- `keywords` / `keywordCn`：英文/中文关键词；首行是 `phone stand`（手机支架）。
- `searches` / `searchesGrowth`：月搜索量/增长率；`searchesRank`：ABA 周排名。
- `purchases` / `purchaseRate`：月购买量/购买率。
- `impressions` / `clicks`：展示量/点击量。
- `products` / `supplyDemandRatio`：商品数/需供比。
- `trafficPercentage`：内测版流量占比（首行 14.85%）。
- `titleDensityExact` / `cprExact`：标题密度/CPR。
- `bid` / `exactPpc`：PPC 竞价/精准 PPC；首行 `bid=0.2`、`exactPpc=1.17`。
- `monopolyClickRate` / `top3ClickingRate` / `top3ConversionRate`：ABA 集中度/点击前三点击率/转化率。
- `relationVariationsItems`：相关 ASIN/变体列表（ASIN、标题、价格、评分、评论数、流量占比），是「相关ASIN」列的数据来源。

## 8. 排序、分页、每页条数

- 默认排序以页面为准；本次未改排序。
- 每页 **50** 条。
- 实测总数 **2,246**，第 1 页 **50** 行，`pageSize=50`、`currentPage=1`。
- 分页用 `read-table.js` 的 `total/pageSize/currentPage`；翻页后重新读表。
- 选「全部变体」的预计词数是 2,246；选「畅销变体/当前变体」是 2,092。实际 total 与所选方式一致。

## 9. 导出

- 结果工具栏有「加入词库」「全部加入词库」「导出明细」「导出」。
- 本次验证**没有点击导出/加入词库**。导出是异步任务；加入词库会改账号数据。需要时按 `workflow.md` 的导出规则单独确认。

## 10. 空态与页面坑

- 空态原文：**「主人~暂无相关数据哦！」**（注意和流量词对比的「主人-暂无相关数据哦!」标点不同）。
- 触发方式：清空 ASIN 后输入无效 ASIN `B000000000` → 立即查询 → 拓词方式弹窗里各选项词数为 0 → 选「使用 全部变体」→ 结果页 `rowCount=0`、`total=0`、`empty=true`。
- 空态下结果表头仍是 16 列（和正常结果一致），但 `total=0`。
- ASIN 输入是自定义 token 组件：`bsk read` 可读到 `textarea/input` 的 placeholder；「清除」按钮有时被遮挡，点失败时先 `bsk sync` 再点。
- 拓词方式弹窗必须选；点文字标签可能不生效，点选项右侧的词数按钮（如 `2,246`）才会执行。
- 输入支持父体或子体 ASIN；页面可能自动识别/汇总变体，报告要写实际选择的拓词方式。
- 结果区的「相关ASIN」列是变体/相关 ASIN 列表，不是结果行本身。

## 12. 典型配方

1. **竞品词库**：输入 3–10 个竞品 ASIN → 全部变体 → 立即查询 → 按流量占比/月搜索量读前 50。
2. **共性词/差异词**：多个竞品一起拓词 → 看「相关ASIN」里哪些 ASIN 共享同一个词；差异词再拿去「流量词对比」验证。
3. **低竞争词**：过滤面板设 需供比 ≥1、标题密度 ≤10、广告竞品数 ≤N → 开始筛选。
4. **父/子体汇总**：输入任一子体 ASIN → 选「全部变体」→ 页面汇总变体词库；报告写清是全部变体。
5. **继续下钻**：把词拿到「关键词反查」看具体 ASIN，或到「关键词转化率」看转化率。
