# 选市场（market research）

## 1. 用途

按亚马逊类目汇总市场数据，用一组市场指标（销量、销售额、价格、评分、BSR、卖家数、集中度、新品表现等）评估细分市场的机会与竞争度。

- 适合：判断一个类目/细分市场值不值得做；横向比较多个细分市场；看新品占比和集中度。
- 不适合：按单个 ASIN 查竞品（用「竞品分析」）；按关键词反查流量（用「关键词反查」）；按销量筛具体商品（用「选产品」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/market-research`
- 导航：工作台「产品」→ 大数据选品 → **选市场 NEW**。
- 查询后 URL 形如
  `https://www.sellersprite.com/v3/market-research?dataDimension=singleMonth&market=US&page=1&size=60&monthName=bsr_sales_nearly&nodeIdPaths=%5B%221055398%22%5D...`
- 本页的站点、月份、类目和部分筛选条件会写入 URL（例如 `nodeIdPaths`、`minTotalSales`），但完整条件仍以页面回显为准。

## 3. 站点选择

- 查询栏「选择站点」是一排按钮：美国站 / 日本站 / 英国站 / 德国站 / 法国站 / 意大利 / 西班牙 / 加拿大 / 印度站 / 墨西哥。
- US 用 USD（页面价格显示 `$`）；CA 用 CAD（页面显示 `C$`）。切换站点后必须重新筛选并核对币种。
- 本页 US 已完整验证；CA 只确认过站点控件，未验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 NEW / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库 / 自定义品类 / 插件端报告 / 我的收藏 / 查询历史。
2. **选择站点**：一排站点按钮。
3. **数据维度**：单月静态数据 / 近24个月动态趋势。
4. **选择月份**：最近30天 + 2026-10 起的月份按钮。
5. **选择类目**：按钮「选择一个或多个类目和子类目」，点开是类目树弹窗；勾选后点「确认选择」。
6. **样本设置**：新品定义（默认「半年内上架」）、Listing样本数量（默认「前100名」）、头部Listing数量（默认「前10名」）。
7. **我的模式 / 隐藏过滤条件**：保存或收起筛选面板。
8. **指标分组**：市场需求指标、市场波动指标、市场竞争指标；每组下方是「最小值 ~ 最大值」输入框。
9. **操作按钮**：开始筛选、重置条件、保存当前模式。
10. **结果区**：标题「查询结果|选市场」；表格 + 分页。

## 5. 必填输入与可选筛选

- 类目：没有类目时结果没有意义。点「选择一个或多个类目和子类目」→ 点类目名称（不是点隐藏的 checkbox）→「确认选择」。
- 站点：默认美国站；切换后要重新筛选。
- 数据维度：单月静态数据（默认）/ 近24个月动态趋势。
- 月份：默认「最近30天」；也可选具体月份（2026-10、2026-09…）。
- 可选区间（每组都是 最小值 ~ 最大值）：
  - 市场需求指标：月总销量、月均销量、月均销售额、平均评分数、平均BSR、平均价格、平均星级、平均重量、平均体积、平均毛利率、头部Listing平均BSR、头部Listing月总销量、头部Listing月均销量、头部Listing月均销售额、商品总数。
  - 市场波动指标：新品数量占比、新品数量、新品销量占比、新品平均评分数、新品平均价格、新品平均星级、新品月均销量、新品月均销售额。
  - 市场竞争指标：品牌数量、卖家数量、平均卖家数、商品集中度、品牌集中度、卖家集中度、A+数量占比、FBA占比、FBM占比、Amazon自营占比、卖家所属地、卖家所属地占比。
- **「开始筛选」是查询按钮**：填完条件必须点它，结果区才会刷新。
- 「重置条件」清空筛选表单；「保存当前模式」保存当前筛选组合。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/market-research" --json`；确认标题含「选市场」、站点是美国站。
2. 点「选择一个或多个类目和子类目」，选目标类目，点「确认选择」。
3. 需要时切换数据维度/月份；默认先保持「单月静态数据」+「最近30天」。
4. 点「开始筛选」，等结果标题变成「查询结果|选市场」并出现表格。
5. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`，能读到 `total/pageSize/currentPage`）。`bsk extract table` 会把表头表/表体表拆开，表体只给 `c1..cN` 生成列名，不建议作为首选。
6. 动作后重新 `bsk sync` 再读；不要凭点击成功就报数。

## 7. 结果表关键列

实测表头（2026-11-14，US，`Home & Kitchen`，最近30天）：

`#`、`细分市场数据解释`、`样本数量`、`月总销量`、`月均销量 头部商品`、`月均销售额 头部商品`、`平均评分数 平均星级`、`平均BSR 头部商品`、`平均卖家数 平均价格`、`卖家类型`、`集中度指标`、`新品数量 新品占比`、`商品总数`、`退货率 同类目均值`、`操作`。

`read-table.js` 返回的 item 关键字段：

- `nodeLabelName` / `nodeLabelLocale`：英文/中文细分市场名；`nodeLabelPath` / `nodeLabelPathLocale`：完整类目路径。
- `totalSales`：月总销量；`avgSales`：月均销量；`avgRevenue`：头部商品月均销售额；`avgPrice`：平均价格。
- `avgReviews`：平均评分数；`avgRating`：平均星级；`avgBsr`：平均BSR；`avgSellers`：平均卖家数。
- `brands` / `sellers`：品牌数/卖家数；`l1NewCount` / `l1NewRatio`：新品数量/占比（口径受页面「新品定义」影响）。
- `fbaRatio` / `amzRatio` / `fbmRatio`：卖家类型占比；`top3/top10/top20...`：集中度指标。
- `currency`：`USD`；`currentMonth`：页面月份代码。
- `nodeImageDtos`：样本商品图（最多 10 个 ASIN/图片），不是结果行本身。

## 8. 排序、分页、每页条数

- 默认排序：`total_sales` 降序（URL `order={"field":"total_sales","desc":true}`）。
- 每页 **60** 条（URL `size=60`）。
- 实测总数 **1,611**，第 1 页读取 **60** 行，`pageSize=60`、`currentPage=1`。
- 分页用 `read-table.js` 的 `total/pageSize/currentPage`；翻页后重新读表。
- 结果表是「表头表 + 表体表」分开渲染；`bsk extract table` 需要分别取，表体列名是生成的 `c1..cN`，所以优先 `read-table.js`。

## 9. 导出

- 本次验证**没有提交导出任务**，结果区的 VOM 也没有出现「导出」按钮。
- 如果页面后续出现导出入口，按 `workflow.md` 的导出规则：先确认筛选条件和总数，单独征得用户同意，只提交一次，到「我的导出」看状态。

## 10. 空态与页面坑

- 空态原文：**「很抱歉，暂无结果！」**，下面还有：
  - 建议：
  - 1、重新选择类目；
  - 2、重新选择过滤条件（先重置条件）；
  - 3、系统内置了一些推荐选品模式，您可以直接拿来参考。
- 触发方式：把「月总销量」最小值设为 `999999999`，点「开始筛选」；实测 `total=0`、`currentPage=1`。
- 类目树：点类目名称才会选中；直接点隐藏的 checkbox 会报 `element_not_visible`。选中后「已选 (N)」会变化，再点「确认选择」。
- 筛选条件不保证全部写入 URL；复制 URL 不一定能完整复现筛选。报告必须写页面回显的条件。
- 结果区是表头表/表体表分离；`bsk extract table` 的默认 target 可能先命中表头表（0 行）。
- 页面有「旧版入口」「自定义品类」「我的模式」等入口，本版不展开。

## 12. 典型配方

1. **类目机会初筛**：选一个一级/二级类目 → 保持「单月静态数据」+「最近30天」→ 开始筛选 → 按 `月总销量` 降序读前 60 个细分市场。
2. **找低竞争市场**：在市场竞争指标里设「平均卖家数 ≤ N」「商品集中度 ≤ X%」→ 开始筛选 → 对照月总销量/月均销售额挑候选。
3. **看新品机会**：市场波动指标里设「新品数量占比 ≥ X%」→ 开始筛选 → 结合新品平均价格/评分数判断入场难度。
4. **看长期趋势**：切换「近24个月动态趋势」→ 选月份 → 重新筛选；趋势数据不要和单月静态数据混在一张表里比较。
5. **继续下钻**：用结果行的「细分市场」/「市场分析」入口进入该市场的商品明细或分析页（本版未展开该入口的完整流程）。
