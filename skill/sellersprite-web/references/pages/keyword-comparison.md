# 流量词对比（keyword comparison）

## 1. 用途

把自己的 ASIN 和最多 10 个竞品 ASIN 放在一起，对比它们在近 30 天内进入亚马逊搜索结果前 3 页的关键词，查看每个词在各 ASIN 上的流量占比、周曝光量、自然排名、广告排名、转化效果和曝光位置。

- 适合：找自己和竞品的共同词/差异词；看竞品在哪些词上吃流量；判断某个词的竞争格局。
- 不适合：查单个 ASIN 的全部流量词（用「关键词反查」）；批量拓展多个 ASIN 的词（用「拓展流量词」）；看关键词转化率（用「关键词转化率」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/keyword-comparison`
- 导航：工作台「产品」→ 关键词优化 → **流量词对比**。
- 查询后 URL 形如
  `https://www.sellersprite.com/v3/keyword-comparison?q=B0949DWJCV&t=B014INJCT4,B0BRN58CXR&marketId=1&date=`
- `q` 是自己的 ASIN，`t` 是竞品 ASIN 列表；变体替换后输入框和结果列可能变化，报告以页面回显为准。

## 3. 站点选择

- 查询栏最左侧是站点下拉（默认「美国站」），可切加拿大等站点。
- US 用 USD；CA 用 CAD。切换站点后重新查询并核对币种。
- 本页 US 已完整验证；CA 只确认站点控件，未验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：关键词挖掘 / 关键词反查 / 流量词对比 / 拓展流量词 / 关键词转化率 / 实时查竞价 / 关键词收录 / 关键词词库。
2. **查询栏**：站点下拉、输入自己的ASIN、输入竞品ASIN(最多10个)、立即查询、查询历史。
3. **变体弹窗**：「选择对比的变体」——检测到更畅销变体时，选择「使用畅销变体对比」或「使用当前变体对比」，也可以选「用畅销变体拓词」/「用当前变体拓词」。
4. **结果区**：对比维度栏（对比项 / 流量占比 / 周曝光量 / 自然排名 / 广告排名 / 转化效果 / 曝光位置）、`搜索结果数(已合并去重)`、表格、分页。
5. **结果工具栏**：加入词库、全部加入词库、导出、筛选关键词、复制。

## 5. 必填输入与可选筛选

- 自己的 ASIN：必填，1 个。
- 竞品 ASIN：最多 10 个，空格或逗号分隔；可以只填 1 个竞品。
- 站点：默认美国站。
- 对比维度：流量占比、周曝光量、自然排名、广告排名、转化效果、曝光位置（页面顶部切换）。
- 关键词筛选：结果区的「筛选关键词」。
- 变体选择：有更畅销变体时必须先在弹窗里选一种口径，否则结果不出现。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/keyword-comparison" --json`；确认标题「流量词对比」、站点是美国站。
2. 填自己的 ASIN 和竞品 ASIN；点「立即查询」。
3. 如果出现「选择对比的变体」弹窗：选「使用畅销变体对比」或「使用当前变体对比」。本次选的是「使用畅销变体对比」。
4. 等结果区出现 `搜索结果数(已合并去重)` 和表格；再读表。
5. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`，能读 `total/pageSize/currentPage`）。
6. 不要点「加入词库」「全部加入词库」「导出」；本次只读验证。
7. 结束 `bsk close`。

## 7. 结果表关键列

实测表头（2026-11-14，US，自己 `B0949DWJCV`，竞品输入 `B014INJCT4,B0BRN58CXR`，选畅销变体后）：

`#`、`关键词 数据解释`、`B0949DWJCV (我的)`、`B0BRN58CXR`、`B0BFWL7TKP`、`有效 竞品数`、`ABA 周排名`、`月搜索量`、`购买量`、`展示量`、`点击量`、`商品数`、`需供比`、`操作`。

- 变体弹窗选择畅销变体后，竞品 `B014INJCT4` 被替换成 `B0BFWL7TKP`；输入框也变成 `B0BRN58CXR,B0BFWL7TKP`。这是页面行为，不是输入错误。
- 每个 ASIN 列显示该词在该 ASIN 上的流量占比/排名等信息；`competitorList` 里有每个 ASIN 的 `rankPosition`、`adRankPosition`、`trafficPercentage`、`badges`（如 `AMAZON_CHOICE`、`ADS`）。
- `有效 竞品数` 是去重/有效后的竞品数量，不一定等于输入数量。
- `ABA 周排名` 对应 `searchesRank`；`月搜索量` 对应 `searches`；`购买量`/`购买率` 对应 `purchases`/`purchaseRate`；`展示量`/`点击量` 对应 `impressions`/`clicks`；`商品数`/`需供比` 对应 `products`/`supplyDemandRatio`。
- `clickTop3s` 是点击前三 ASIN（ASIN、点击率、转化率、标题、图片），不是结果行本身。
- 结果区顶部还有 `对比项`：流量占比、周曝光量、自然排名、广告排名、转化效果、曝光位置。

## 8. 排序、分页、每页条数

- 默认排序以页面为准；本次未改排序。
- 每页 **50** 条。
- 实测总数 **1,553**（`搜索结果数(已合并去重): 1,553`），第 1 页 **50** 行，`pageSize=50`、`currentPage=1`。
- 分页用 `read-table.js` 的 `total/pageSize/currentPage`；翻页后重新读表。
- `搜索结果数(已合并去重)` 与分页 total 应一致；不一致时以页面正文和 total 一起记录。

## 9. 导出

- 结果工具栏有「加入词库」「全部加入词库」「导出」「筛选关键词」「复制」。
- 本次验证**没有点击导出/加入词库**。导出和写词库都有副作用：导出需单独确认，加入词库会改账号数据，本版不执行。

## 10. 空态与页面坑

- 空态原文：**「主人-暂无相关数据哦!」**；实测用无效 ASIN `B000000000` 查询后：
  - `搜索结果数(已合并去重): 0`
  - `read-table.js rowCount=0`、`total=null`、`empty=true`
  - 空态下表头不再包含 ASIN 列，只剩 `#`、`关键词 数据解释`、`有效 竞品数`、`ABA 周排名`、`月搜索量`、`购买量`、`展示量`、`点击量`、`商品数`、`需供比`、`操作`。
- 有更畅销变体时会先弹「选择对比的变体」；不选就不会出结果。弹窗里的「使用畅销变体对比」和「用畅销变体拓词」是两个不同动作，本页只选「对比」。
- 竞品 ASIN 最多 10 个；逗号/空格分隔。无效/重复 ASIN 会让 `有效 竞品数` 小于输入数量。
- 旧结果可能仍在页面上；复查询后核对 `搜索结果数` 和首行关键词是否变化。
- 不要把 ASIN 列当成固定 3 列；它会随输入/变体替换变化。

## 12. 典型配方

1. **自己和竞品的共同词**：自己 ASIN + 1–3 个竞品 → 立即查询 → 选畅销变体对比 → 按流量占比/搜索量读前 50。
2. **找差异词**：对比多个竞品，看某个词只出现在竞品列、自己列为空/低占比 → 作为广告或 Listing 候选。
3. **看竞品广告位**：看 `competitorList[].badges` 里的 `ADS`、`AMAZON_CHOICE`，以及 `adRankPosition`。
4. **看词的转化集中度**：用 `clickTop3s` 的 clickRate/conversionRate 判断头部 ASIN 是否吃掉大部分点击/转化。
5. **继续下钻**：把词拿到「关键词反查」看还有哪些 ASIN 在吃这个词，或到「关键词转化率」看转化率筛选。
