# 实时查竞价（real-time bidding）

## 1. 用途

输入单个 ASIN，创建一个异步查询任务，查看该 ASIN 在亚马逊广告上的实时建议竞价：周搜索量、现排名、展示/点击、六种竞价策略（提高和降低/仅降低或固定 × 精准/广泛/词组）、ABA 集中度和点击前三 ASIN。

- 适合：选品前估算推广成本；找“低竞价高转化”的词；判断某个 ASIN 的关键词竞争度；给广告架构准备建议竞价。
- 不适合：批量查多个 ASIN（本页一次一个 ASIN）；查关键词转化率（用「关键词转化率」）；查 ASIN 的流量词（用「关键词反查」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/real-time-bidding`
- 导航：工作台「产品」→ 关键词优化 → **实时查竞价**。
- 任务结果在详情页：
  `https://www.sellersprite.com/v3/real-time-bidding/detail?marketId=1&parentTaskId=<task-id>&taskId=<task-id>&adType=sp&q=<ASIN>...`
- 详情页标题形如 `B07Z82895W|实时查竞价|卖家精灵`。

## 3. 站点选择

- 查询栏有站点下拉（默认「美国站」）；详情页按任务的 `marketId`/站点展示。
- US 用 USD（页面显示 `$`）；CA 用 CAD。切换站点后重新建任务并核对币种。
- 本页 US 已完整验证；CA 只确认站点控件，未验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：关键词挖掘 / 关键词反查 / 流量词对比 / 拓展流量词 / 关键词转化率 / 实时查竞价 / 关键词收录 / 关键词词库。
2. **查询栏**：站点下拉、输入单个ASIN、新建查询任务、查询历史、示例 ASIN。
3. **任务列表**：`#`、ASIN信息、关键词信息、查询时间、查询状态、查询次数、操作；工具栏有导出、批量删除。
4. **新建任务弹窗**：任务类型（亚马逊推荐关键词 / 输入指定关键词）、ASIN 输入、确定/取消。
5. **详情页**：`更新至: 2026第45周(...)`、排序下拉、导出、结果表、分页。
6. **任务操作**：再次查询、查看、删除。

## 5. 必填输入与可选筛选

- ASIN：必填，**单个** ASIN，例如 `B07Z82895W`。
- 任务类型：
  - 亚马逊推荐关键词（默认）
  - 输入指定关键词
- 站点：默认美国站。
- 详情页排序：周搜索量、现排名、展示量、点击量等；升序/降序。
- 详情页广告类型：SP/SB（页面下拉）。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/real-time-bidding" --json`；确认标题「实时查竞价」、站点是美国站。
2. 点「新建查询任务」；在弹窗里确认任务类型（默认亚马逊推荐关键词），填单个 ASIN，点「确定」。
3. 任务出现在列表，状态先是 **查询中**。**不要重复提交**；本次只创建一个任务。
4. 轮询 `bsk sync` + `read-table.js`，直到 `taskStatus` 从 2（查询中）变成 3（已完成）；页面状态列显示「已完成」。
5. 点任务行的「查看」；它会打开新的详情标签页。用 `bsk tab list --session <SID> --json` 找到新标签，`bsk tab select <tab-id>` 后再 `bsk sync`。
6. 详情页读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`）。
7. 不要点「再次查询」「删除」「批量删除」「导出」；本次只读验证，任务保留在查询历史。
8. 结束 `bsk close`。

## 7. 结果表关键列

任务列表表头：`#`、`ASIN信息`、`关键词信息`、`查询时间`、`查询状态`、`查询次数`、`操作`。

详情表头（实测 2026-11-14，US，ASIN `B07Z82895W`，任务类型亚马逊推荐关键词）：

`#`、`关键词 数据解释`、`周搜索量`、`现排名`、`展示量 点击量`、`提高和降低 (精准)`、`提高和降低 (广泛)`、`提高和降低 (词组)`、`仅降低/固定 (精准)`、`仅降低/固定 (广泛)`、`仅降低/固定 (词组)`、`ABA集中度`、`点击前三ASIN`、`操作`。

`read-table.js` 的 `headers` 会把同一组表头重复 3 次（页面多表结构）；以**前 14 项**为准。

`read-table.js` 返回的 item 关键字段：

- `keyword` / `keywordCn`：英文/中文关键词；首行 `iphone duo case`（iPhone 双件手机壳）。
- `weekSearchNum`：周搜索量；`rank`：现排名；`displayNum`/`clickNum`：展示量/点击量。
- `autoSponsorExact` / `autoSponsorBroad` / `autoSponsorPhrase`：提高和降低（精准/广泛/词组）。
- `manualSponsorExact` / `manualSponsorBroad` / `manualSponsorPhrase`：仅降低/固定（精准/广泛/词组）。
- 本次这些 sponsor 字段返回 `1`；页面显示的建议竞价和区间以 VOM/页面为准（首行 6 列均为 `$1.00`，区间 `$0.79 - $1.25`）。
- `abaConcentrationDegree`：ABA 集中度（首行 20.16%）。
- `topClickAsin`：点击前三 ASIN（ASIN、点击率、转化率、图片）；首行 `B0HGQK86HR` 7.73%/4.35%、`B0HHF2JT8G` 7.19%/4.06%、`B0HB4M1C4T` 5.24%/1.89%。
- `updatedTime`：任务更新时间；`market`/`asin`/`currencyUnit`/`cvsShareRate`。

## 8. 排序、分页、每页条数

- 任务列表：本次 1 个任务，`total=1`、`pageSize=50`、`currentPage=1`。
- 详情页：实测 `total=200`，第 1 页 **50** 行，`pageSize=50`、`currentPage=1`。
- 详情页默认排序：周搜索量降序（页面下拉显示「周搜索量 / 降序」）。
- 翻页/排序后重新读表；不要沿用上一页数据。

## 9. 导出

- 任务列表和详情页都有「导出」按钮。
- 本次验证**没有点击导出**。导出是异步任务；需要时按 `workflow.md` 的导出规则单独确认。

## 10. 空态与页面坑

- **任务式页面**：提交后不是立刻出结果；状态先「查询中」，完成后才是「已完成」。本次实测 `taskStatus=2` 对应查询中，`taskStatus=3` 对应已完成；其他状态未映射，不要猜。
- 只允许创建 **1 个**示例任务；不要为了空态再建第二个任务。本次未触发空态。
- 「查看」会打开新的详情标签页；不要在旧标签页里等结果。用 `bsk tab list`/`bsk tab select` 切换。
- 任务行有「再次查询」「删除」「批量删除」；本版只读，不点。
- 详情表头重复 3 次是页面多表结构，不是读取错误；取前 14 项。
- sponsor 字段在 item 里可能是 `1`（标志/占位），实际金额看页面列；不要用 item 的 1 当 $1.00 报数。
- 任务会留在查询历史；报告里记录任务状态、创建时间、数据周，不记录账号信息。

## 12. 典型配方

1. **选品成本估算**：输入候选 ASIN → 亚马逊推荐关键词 → 等完成 → 看六种竞价策略的建议价和区间。
2. **找低竞价词**：详情页按周搜索量降序 → 过滤高搜索量、低建议竞价的词。
3. **看竞争集中度**：看 `abaConcentrationDegree` 和 `topClickAsin` 的点击/转化集中度。
4. **对比历史任务**：任务行有「对比历史任务」入口（本次未展开）。
5. **后续使用**：把词和竞价拿到「关键词挖掘」/「关键词转化率」继续分析；本 skill 不写广告。
