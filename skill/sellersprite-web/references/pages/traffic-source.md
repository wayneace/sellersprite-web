# 查流量来源（traffic source）

## 1. 用途

看一个 ASIN（或关键词）的流量在**自然搜索、亚马逊推荐位、广告位**之间怎么分：每个来源有多少关键词，以及全部流量词、自然流量占比。

- 适合：判断一个商品是不是靠广告堆流量；找自然流量强的竞品；看 AC/ER/4星/HR 推荐位的占比；一次对比多个变体。
- 不适合：看具体是哪些词（用「关键词反查」）；看关联流量/出单词（用对应页面）。

## 2. URL 与导航

- 查询页 URL：`https://www.sellersprite.com/v3/reversing`
- 结果页 URL 会变成
  `https://www.sellersprite.com/v3/reversing/sources?asin=B07H9PZDQW&marketId=1&date=`
- 导航：工作台「产品」→ 运营推广 → **查流量来源**；页面子导航第二项。
- 查询后标题变为 `<ASIN>|查流量来源|卖家精灵`。

## 3. 站点选择

- 查询栏最左侧是国家下拉「美国站」，旁边是月份「最近30天」。
- US 用 USD，CA 用 CAD；价格等货币字段随站点。
- 切换站点后重新查询；核对币种和结果。详见 [sites.md](../sites.md)。
- CA 只确认了站点控件可切，未逐页验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：广告洞察 / 查流量来源 / 关联流量 / 出单词反查 / AI评论分析2.0 / 产品监控 / 关键词监控 / 店铺上新监控。
2. **查询栏**：国家下拉、月份（默认最近30天）、输入框「输入父(子)体ASIN(最多20个)或关键词，多个ASIN以逗号区分」、立即查询、查询历史、示例。
3. **结果区**：结果统计文案（「搜索到 N 个同组变体，另有 M 个变体因未进入前3页而未展示」）、产品对比/加入自定义品类/加入产品库/复制ASIN/导出、结果表、分页。
4. **结果表**：每个 ASIN 一行，列出全部流量词和各来源关键词数。

## 5. 必填输入与可选筛选

- 输入必填：一个或多个父/子体 ASIN（最多 20 个，逗号分隔），或一个关键词。
- 月份：空 = 最近 30 天；也可选自然月。
- 排序：结果表可按列排序（旧 CLI 默认 order=1、降序）。
- 每页条数：页面提供 20/50/100（旧知识；本次实测 `pageSize=100`）。
- 关键词输入时，返回的是「近 30 天内进入过该关键词搜索结果前 3 页」的产品。
- 输入多个 ASIN 会按同组变体聚合展示；变体未进前 3 页的不展示。

## 6. 操作流程

1. 打开页面，确认国家、月份。
2. 在输入框填 ASIN（或关键词），点「立即查询」。
3. 等待结果统计文案和结果表出现；确认「搜索到 N 个同组变体」。
4. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`）。
5. 翻页/排序后重新读表；记录页码、每页条数。
6. **空态判断以页面正文为准**：无效 ASIN 时表格会消失，但 Vue store 可能残留上一次的行（见第 10 节）。

## 7. 结果表关键列

实测表头（2026-11-12，US，ASIN `B07H9PZDQW`）：

`#`、`产品信息`、`数据解释`、`流量来源`、`全部流量词`、`自然搜索词`、`AC推荐词`、`ER推荐词`、`4星推荐词`、`HR推荐词`、`SP广告词`、`视频广告词`、`品牌广告词`、`操作`。

- 产品信息列：标题、变体数、颜色/尺寸、价格、评分/评分数、ASIN；流量来源列显示「自然搜索 / PPC广告」等标识。
- 各来源计数是**关键词个数**，不是订单或流量百分比。
- 全部流量词 = 推荐 + 自然 + 广告词合并去重后的总数；各来源会重叠，**不能把各来源相加当分母**。
- 自然流量占比自己算：`自然搜索词 / 全部流量词 × 100%`；页面可能不直接显示百分比。
- 首行样例（`B07H9PZDQW`）：全部流量词 `1,012`，自然搜索词 `954`，AC `0`，ER `0`，4星 `0`，HR `4`，SP `156`，视频 `0`，品牌 `0`；自然占比 ≈ `94.27%`。
- 字段口径见 [fields.md](../fields.md)。

## 8. 排序、分页、每页条数

- 结果按产品（ASIN/变体组）计行；实测 `rowCount=12`、`total=12`。
- 每页条数可选 20/50/100；本次实测 `pageSize=100`。
- 分页组件是 Element UI，`read-table.js` 能读 `total/pageSize/currentPage`。
- 结果统计文案里的「N 个同组变体」与分页 total 可能一致；以页面文案 + 分页为准。

## 9. 导出

- 结果区有「导出」按钮；导出是异步任务。
- 只提交一次；到「我的导出」看状态；文件出现后用 `bsk download`。
- 本页验证**没有提交导出任务**。

## 10. 空态与页面坑

- 无效 ASIN 时页面显示：「未能找到近30天或对应月份进入过关键词搜索结果前3页的产品或ASIN对应的流量来源」，原因包括 ASIN 错误/与站点不匹配、新 ASIN 或访问量太少、关键词拼写/语言不匹配。
- **空态时表格视觉上消失，但 Vue store 可能保留上一次查询的行**：实测无效 ASIN 后 `read-table.js` 仍返回 `rowCount=12`、`total=12`（上一次 `B07H9PZDQW` 的数据）。判断空结果必须看页面正文/截图，不能只看片段返回值。
- 空态时分页也可能保留旧 total（实测仍为 12）；不要用它报数。
- 优先用最新 `observe` 的 ref 或可见标签；只有在 `observe` 没有给出输入框/按钮 ref 时，才用下面的 CSS 兜底：
  - 输入 `input[placeholder^='输入父(子)体ASIN']`
  - 查询 `.el-input:has(input[placeholder^='输入父(子)体ASIN']) .el-input-group__append button.my-btn`
- 查询后 URL 从 `/v3/reversing` 变为 `/v3/reversing/sources?...`，报告要用结果页 URL。

## 11. 验证清单

- [ ] URL 是 `/v3/reversing/sources` 且 `asin` 参数正确。
- [ ] 站点和币种一致；月份与页面显示一致。
- [ ] 输入是 ASIN 还是关键词，写清楚。
- [ ] 「搜索到 N 个同组变体」、分页 total、读取行数都记录。
- [ ] 自然占比用 `自然搜索词 / 全部流量词` 计算，并注明来源列。
- [ ] 表头与文档一致。
- [ ] 空结果必须由页面正文确认，不能只信片段。

## 12. 典型配方

1. **ASIN → 流量结构**：输入 ASIN → 最近30天 → 立即查询 → 读表；看自然搜索词与 SP 广告词的比例。
2. **广告占比高的竞品**：按 SP 广告词降序（或逐个看），找自然占比低的商品。
3. **自然占比低的商品**：计算 `自然/全部`，低于 50% 说明流量更依赖广告/推荐。
4. **再跳到关键词反查**：把同一个 ASIN 拿到「关键词反查」看具体词和排名。
