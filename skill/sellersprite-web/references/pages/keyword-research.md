# 关键词选品（keyword research）

## 1. 用途

把「关键词」当成一个市场来筛：不看单个词的历史，而是按需求、增长、竞争、货值等市场指标，找出值得进入的关键词市场。

- 适合：找高需求低竞争的词市场；找持续增长/季节性市场；按类目筛词；为「关键词挖掘」「选产品」提供候选。
- 不适合：一个种子词能拓出哪些词（用「关键词挖掘」）；一个 ASIN 靠哪些词拿流量（用「关键词反查」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v2/keyword-research`
- 导航：工作台「产品」→ 大数据选品 → **关键词选品**；页面子导航第四项。
- 查询后 URL 带完整条件，例如
  `?station=US&order.field=searches&order.desc=true&...&marketId=1&month=202610&minSearches=1000&...`
- **v2 跳转的坑**：旧 CLI 记录「v2 页面一启动就跳到 `/v3/keyword-miner`」。2026-11-12 live 验证**没有复现**：裸路径可稳定停留在 v2，页面标题为「关键词选品 - 亚马逊关键词选品工具」。如果以后页面开始跳转，按 `troubleshooting.md` 记录实际落点，优先用带完整查询参数的 URL 进入；不要凭旧笔记直接断言已跳转。

## 3. 站点选择

- 站点是按钮排（美国/日本/英国/德国/法国/意大利/西班牙/加拿大/印度/墨西哥/巴西站/澳洲站/阿联酋/沙特），默认美国。
- US 用 USD，CA 用 CAD；价格、PPC 竞价等货币字段随站点。
- 旧 CLI 的 UI 模式只验证过 US；本版只确认了「加拿大」按钮存在，**未跑 CA 查询、未验证 CA 数据/币种**。详见 [sites.md](../sites.md)。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库；右侧我的关注 / 关键词词库 / 查询历史。
2. **顶部条件区**：选择站点、选择月份、推荐模式（我的模式/热门市场/趋势市场/类目飙升榜/类目热搜榜）、选择类目（大类复选框）。
3. **筛选面板**：需求、增长、竞争、商品四组区间输入，底部「开始筛选」「重置条件」「保存当前模式」。
4. **结果工具栏**：关键词对比、加入词库/全部加入词库、导出明细/导出、搜索结果数、复制、排序方式、升降序、确定。
5. **结果表**与**自定义分页**（不是 Element UI 的 `.el-pagination`）。

## 5. 必填输入与可选筛选

- 没有必填关键词；这是一个市场筛选器，空条件 + 月份也能查。
- 月份：页面月份按钮，默认最新月（实测 2026-10）；URL `month=YYYYMM`。
- 市场周期（页面下拉）：`N` 一般性市场 / `S1`–`S3` / `S4`–`S6` / `S7`–`S9` / `S10`–`S12` 季节性市场（按旺季月份分组）/ `I` 持续增长 / `D` 持续衰退。
- PPC 竞价匹配方式（URL `keywordBidMatchType`）：`phrase` / `exact` / `broad`；实测默认 `exact`。
- 排序字段：月搜索量、购买率、月购买量、展示量、点击量、增长率、同比增长率、近3月增长率、点击总占比、转化总占比、货流值、需供比、商品数；升降序。
- 筛选组（页面可见标签）：
  - **需求**：月搜索量、月购买量、购买率、展示量、点击量。
  - **增长**：月搜索量增长率、同比增长值、月搜索量近3个月增长值、月搜索量同比增长率、月搜索量近3个月增长率。
  - **竞争**：商品数、SPR、货流值、需供比、标题密度、Top3 点击总占比、Top3 转化总占比、PPC 竞价。
  - **商品**：平均价格、平均评分数、平均星级、单词个数。
- 类目用复选框选大类；「仅包含该市场」是新细分市场开关。
- 顶部「推荐模式」（热门市场/趋势市场等）会改写筛选条件，用了要重新核对回显。

## 6. 操作流程

1. 打开页面，确认站点、月份。
2. 选类目、市场周期，填需求/增长/竞争/商品区间。
3. 点筛选面板底部的「开始筛选」；等待工具栏出现「搜索结果数」和结果表。
4. 动作后重新 `observe`；「开始筛选」点击成功不等于查询生效。
5. 读取用 `bsk extract table`（本页是传统 HTML 表格）；`read-table.js` 在本页返回 `source:"none"`，不要用它。
6. 分页是页面自定义控件（`1-50/1000+ 首页 Previous 1 2 3 4 5 下一页 Next 50条/页 跳转至 页 确定`），翻页后重新抽取。

## 7. 结果表关键列

实测表头（2026-11-12，US，2026-10，月搜索量 ≥1000）：

`#`、`关键词`（含中文翻译）、`展示10条相关产品`、`搜索量趋势`、`月搜索量`、`月购买量 / 购买率`、`展示量 / 点击量`、`增长率`、`同比增长 / 近3月增长`、`ABA 集中度`、`ABA 排名`、`货流值`、`PPC竞价 精准`、`需供比 / 商品数`、`市场分析`、`操作`。

- 每个关键词在主行下面还有一条**详情行**：所属类目占比、市场周期（含旺季月份）、SPR、标题密度；再下面是一条空的分隔行。所以 `extract table` 的原始行数约为关键词数的 3 倍（实测 50 个词 → 149 个 `<tr>`）。
- 关键词同时给英文和中文翻译；只取英文列做后续查询。
- 字段口径见 [fields.md](../fields.md)：`展示量`/`点击量` 是该词结果页所有 ASIN 的总量，不是单个 ASIN。

## 8. 排序、分页、每页条数

- 固定 **50 条/页**（页面无每页条数下拉；URL 也没有 size 参数）。
- 分页控件是自定义的，文本形如 `1-50/1000+`，带首页/Previous/页码/下一页/Next/50条/页/跳转至 页/确定。
- 工具栏显示「搜索结果数: 5000+」，分页 footer 显示 `1-50/1000+`——两个数口径不同，报告两个都写，并注明来源。
- 翻页/改排序/改条件都会重新查询；每次读完重新确认页码和总数。

## 9. 导出

- 结果工具栏有「导出明细」和「导出」；导出是异步任务。
- 只提交一次；到「我的导出」看状态；文件出现后用 `bsk download`。
- 本页验证**没有提交导出任务**，只确认了按钮存在。

## 10. 空态与页面坑

- 条件过严时页面显示「该关键词暂未收录」，并给出可能原因：关键词拼写错误或月搜索量太低、所选国家与关键词不匹配、检索条件太严格；建议减少关键词短语。
- 空态下没有结果表；`extract table` 可能抽不到行。
- **v2 跳 v3**：旧笔记说会跳 `/v3/keyword-miner`；本次 live 未复现。每次先看 `location.href` 和页面标题，跳转了就以落点页面的规则为准。
- `read-table.js` 在本页读不到数据（`source:"none"`）；本页读取用 `bsk extract table`。
- 页面底部还有一个「输入关键词」输入框（用于校验单个词是否收录），它和筛选条件不是一回事，不要把它当成主查询。
- 「开始筛选」是 `type=submit` 按钮；页面上有多个 submit 按钮时，用表单元范围定位：
  `form:has(input[name='minSearches']) button[type='submit']`。

## 12. 典型配方

1. **找增长市场**：市场周期选「持续增长市场」→ 月搜索量 ≥10000 → 近3个月增长率 ≥10% → 开始筛选。
2. **找低竞争高需求词**：需供比 ≥1 + 标题密度 ≤10 + 商品数 ≤20000 + 月搜索量 ≥1000。
3. **类目内筛词**：勾选一个大类（如 Sports & Outdoors）→ 月搜索量 ≥5000 → 按购买率降序。
4. **跳到下一步**：把筛出的词拿到「关键词挖掘」拓词，或拿到「选产品」按销量/价格找商品。
