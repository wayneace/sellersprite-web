# 利润计算器（profit calculator）

## 1. 用途

按 FBA/FBM 费用、采购成本、头程、佣金、广告/促销、售后和仓储，估算商品的净利润、净利率和 ROI。

- 适合：上架前估算利润；比较不同售价/成本/运费下的利润；给选品和定价做参考。
- 不适合：替代真实财务结算；查销量（用销量预测）；查关键词/流量（用关键词反查、查流量来源）。
- 页面有 `FBA利润计算器`、`FBM利润计算器`、`折后价计算器` 三个 tab；本页验证 FBA 模式。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/calculator/index`
- 导航：工作台「免费工具」→ **利润计算器**。
- 页面标题：`利润计算器 - 亚马逊利润计算器工具 | 卖家精灵`。

## 3. 站点选择

- 表单顶部有站点下拉，默认「美国站」；US 用 USD，人民币按当前汇率折算。
- 站点下拉实测包含：美国站、日本站、英国站、德国站、法国站、意大利、西班牙、加拿大、印度站、墨西哥、澳洲站。
- 本页 US 已完整验证；CA 只确认站点控件含「加拿大」，未选择、未计算，CA 数据/币种未验证。

## 4. 页面结构

1. **顶部 tab**：`FBA利润计算器`（默认）、`FBM利润计算器`、`折后价计算器`。
2. **站点/汇率**：站点下拉、当前汇率 `(USD/CNY)`、`更新汇率`。
3. **产品规格**：包装尺寸（长/宽/高，cm/inches/dm/m）、体积、包装重量（g/kg/ounces/pounds）、体积重量、体积重系数（5000/6000）。
4. **商品收入**：商品售价 `$`、收取买家的运费 `$`。
5. **商品成本**：采购成本 `￥`、头程运费（海运/空运/快递 + `￥`）、其他成本 `￥`。
6. **营销成本**：站内广告 `%`、站内促销成本 `%`、站外促销成本 `%`。
7. **售后成本**：退货数、退货率、退货可再售数、退货率阈值、退货处理费、服装和鞋靴。
8. **亚马逊扣费**：商品类别、销售佣金、FBA运费（带 `FBA运费计算` 图标）、关税。
9. **仓储/销量**：仓储时间（月）、仓储费用（1月-9月 / 10月-12月）、销量。
10. **计算结果**：净利润、净利率、ROI、收入小计、成本小计；按 `1月-9月` / `10月-12月` 两档显示。
11. **操作**：`历史记录`、`保存结果`。

## 5. 必填输入与可选筛选

- **商品售价**：必填，USD；本次 `29.99`。
- **采购成本**：必填，CNY；本次 `8.00`。
- **头程运费**：CNY；本次 `2.00`，运输方式保持 `海运`。
- **商品类别**：用于销售佣金；本次选 `其他`，佣金率显示 `15.01%`。
- **FBA运费**：不是直接输入；通过 `FBA运费计算` 图标按包装尺寸/重量计算。本次未填规格，FBA 运费按 0 计。
- **其他字段**：广告/促销/退货/关税/仓储保持默认 0；销量默认 1。
- **汇率**：页面当前 `6.6719`，未点 `更新汇率`。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/calculator/index" --json`；确认标题「利润计算器」、站点美国站。
2. 在 `FBA利润计算器` tab 填：售价 `29.99`、采购成本 `8`、头程运费 `2`。
3. 商品类别选 `其他`（销售佣金自动带出 15.01%）。
4. 头程运费填完后按 `Tab`/失焦提交；本次第一次只 `fill` 时结果仍显示 0，重新 fill 并按 Tab 后变为 ￥2.00。
5. 如需 FBA 运费，点 `FBA运费计算` 图标填包装尺寸/重量后 `计算FBA费用` → `应用计算结果`；本次未填，FBA=0。
6. 读计算结果：净利润、净利率、ROI、收入小计、成本小计。
7. 不要点 `保存结果`；本次不保存、不点 `更新汇率`。
8. 结束 `bsk close`。

## 10. 空态与页面坑

- **FBA 运费不是直接输入**：`FBA运费` 旁是 `FBA运费计算` 图标，需要包装尺寸/重量；本次未填规格，FBA=0。不要把它当成可手填的 5.00。
- **头程运费要失焦提交**：第一次 `fill` 后结果仍为 0，重新 fill 并按 `Tab` 后才变为 ￥2.00；填完要确认结果/字段回显。
- **币种混用**：售价/FBA/佣金是 `$`，采购成本/头程/其他成本是 `￥`；报告必须写清币种，不能把 8.00 当 USD。
- **商品类别影响佣金**：不选类别时销售佣金为 0；选 `其他` 后佣金率 15.01%。报告要写类别。
- **汇率**：默认 6.6719；本次未更新。汇率变化会改变人民币/美元折算。
- **保存/历史**：`保存结果` 会写历史记录；本次未点。
- 本次未触发校验错误/空态；不要猜提示文案。

## 12. 典型配方

1. **估算净利润**：填售价/采购/头程/类别 → 读净利润/净利率/ROI。
2. **比较售价**：改售价 → 重新读净利润和净利率；不要沿用旧结果。
3. **加 FBA 费用**：点 `FBA运费计算` → 填包装尺寸/重量 → `计算FBA费用` → `应用计算结果` → 再读净利润。
4. **看季节性仓储**：改仓储时间/销量，比较 1月-9月 vs 10月-12月。
5. **后续分析**：把利润结果拿到选产品/销量预测；本页不保存、不导出。
