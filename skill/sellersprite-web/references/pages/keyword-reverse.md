# 关键词反查（keyword reverse）

## 1. 用途

反查**一个 ASIN** 靠哪些搜索词拿流量与转化：自然搜索词、广告词、推荐词，以及每个词的排名、流量占比、ABA 排名、竞品数据。

- 适合：看一个竞品/自己商品的主要流量词；区分自然词和广告词；找高转化词和流失词。
- 不适合：从一个种子词拓词（用「关键词挖掘」）；看流量在自然/推荐/广告之间的整体结构（用「查流量来源」）。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/keyword-reverse`
- 导航：工作台「产品」→ 关键词优化 → **关键词反查**；页面子导航第二项。
- 查询后 URL 形如
  `https://www.sellersprite.com/v3/keyword-reverse/?q=B07H9PZDQW&marketId=1&date=&badges=`
- 过滤面板条件不进入 URL；报告筛选条件要读页面回显。

## 3. 站点选择

- 查询栏最左侧是国家下拉「美国站」；右侧月份下拉默认「最近30天」。
- US 用 USD，CA 用 CAD；PPC 竞价、`avgPrice` 等货币字段随站点。
- 切换站点后重新查询；核对币种和 total。详见 [sites.md](../sites.md)。
- CA 只确认了站点控件可切，未逐页验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：关键词挖掘 / 关键词反查 / 流量词对比 / 拓展流量词 / 关键词转化率 / 实时查竞价 / 关键词收录 / 关键词词库。
2. **查询栏**：国家下拉、月份（默认最近30天）、ASIN 输入框、重用上次筛选、立即查询、查询历史、示例 ASIN。
3. **ASIN 概览**：商品标题、卖家、BSR、价格、评分/评分数、上架时间；ASIN 透视、查看所有变体流量词。
4. **流量结构**：搜索流量词占比（全部流量词/自然流量/广告流量）、隐藏图表、查看历史趋势、名词解释。
5. **搜索结果过滤**：流量词类型、流量&转化分类、流量占比、自然/广告排名、ABA周排名、月搜索量、SPR、标题密度、月购买量、购买率、展示量、点击量、商品数、需供比、广告竞品数、点击/转化总占比、PPC竞价、开始筛选、重置条件。
6. **结果表**与分页。

## 5. 必填输入与可选筛选

- ASIN 必填，单个父体或子体 ASIN（或产品链接），如 `B00FLYWNYQ`。
- 月份：空 = 最近 30 天；也可选自然月。
- 流量词类型（复选框）：自然搜索词 / AC推荐词 / ER推荐词 / 4星推荐词 / 品牌广告词 / 视频广告词 / HR推荐词 / SP广告词（可全选）。
- 流量&转化分类：
  - 流量分类：主要流量词 / 精准流量词 / 精准长尾词。
  - 转化分类：有效转化词 / 转化优质词 / 转化平稳词 / 转化流失词 / 无效曝光词。
- 数值筛选：流量占比、自然排名、广告排名、ABA周排名、月搜索量、SPR、标题密度、月购买量、购买率、展示量、点击量、商品数、需供比、广告竞品数、点击总占比、转化总占比、PPC竞价。
- 改完筛选要点「开始筛选」；只填不点不会生效。
- 旧知识：首屏「重置条件」可能被空结果提示遮住；先查询出结果，再考虑重置/筛选。

## 6. 操作流程

1. 打开页面，确认国家、月份。
2. 在 ASIN 输入框填单个 ASIN（或产品链接），点「立即查询」。
3. 等待 ASIN 概览和结果表出现；确认 total 和流量结构卡片。
4. 需要收窄时在「搜索结果过滤」填条件，点「开始筛选」，再观察 total。
5. 读取用 `<skill-dir>/scripts/read-table.js`（本页命中 `el-table-store`）。
6. 翻页后重新读表；记录页码和每页条数。

## 7. 结果表关键列

实测表头（2026-11-12，US，ASIN `B07H9PZDQW`）：

`#`、`关键词`（含中文翻译）、`流量占比`、`流量词类型`、`流量分布`、`自然排名`、`广告排名`、`月搜索趋势`、`ABA 周排名`、`月搜索量 / 增长率`、`SPR`、`标题密度`、`月购买量`、`展示量 / 点击量`、`需供比 / 商品数`、`广告竞品数`、`ABA 集中度`、`PPC竞价`、`操作`。

- 表格用了固定列，`read-table.js` 的 `headers` 会把同一组表头重复 2–3 次；去重后以上表为准。
- 行数据里关键词字段名是 `keywords`（不是 `keyword`），中文翻译是 `keywordCn`。
- **`avgPrice`（页面上的价格相关列）是点击第一的 ASIN 的价格，不是关键词的平均价格**；货币随站点。
- 流量占比是这个词带来的流量占该 ASIN 全部流量词的比例。
- 自然排名 / 广告排名包含页码和位置；`trafficKeywordTypes` 是 PRIMARY / PRECISE / PRECISE_LONG_TAIL，`conversionKeywordTypes` 是 EXCELLENT / STABLE / LOST / INVALID 等。
- PPC 竞价列通常含精准/词组/广泛三种；行数据里另有 `cprExact`（CPR）和 `exactPpc`（精准点击价参考），页面是否默认展示取决于当前列设置，没看到时不要当成缺失。
- 字段口径见 [fields.md](../fields.md)。

## 8. 排序、分页、每页条数

- 默认按**月搜索量**降序（旧 CLI 排序编号 12 = 月搜索量）。
- 每页固定 **50** 条；分页组件是 Element UI，`read-table.js` 能读 `total/pageSize/currentPage`。
- 实测 ASIN `B07H9PZDQW`：`total=1012`、`pageSize=50`、`currentPage=1`。
- 翻页/改筛选都会重新查询；翻页后重新读表。

## 9. 导出

- 页面有「历史全量关键词导出 New」和结果区的导出入口；导出是异步任务。
- 只提交一次；到「我的导出」看状态；文件出现后用 `bsk download`。
- 本页验证**没有提交导出任务**。

## 10. 空态与页面坑

- ASIN 无数据时显示「主人~暂无相关数据哦！该商品可能近期更名或存在历史别名，试试使用别名 … 反查看看吧~」；total=0。
- ASIN 输入框和「立即查询」有稳定的可访问名称；每次动作都用最新 `observe` 的 ref，页面重渲染后不要复用旧 ref。
- 过滤条件不进入 URL；复制 URL 不能复现筛选。
- 结果表表头在 `read-table.js` 里重复，报告前先按可见列去重。
- 旧知识：该页首屏「重置条件」可能被空结果提示遮住，不要盲点。

## 12. 典型配方

1. **ASIN → 主要流量词**：输入 ASIN → 最近30天 → 立即查询 → 按默认月搜索量读表，重点看流量占比和 PRIMARY 词。
2. **ASIN → 广告词**：流量词类型勾选「SP广告词」（可加品牌/视频广告词）→ 开始筛选 → 读广告排名和流量占比。
3. **ASIN → 优质转化词**：转化分类勾选「转化优质词」+「转化平稳词」→ 开始筛选 → 用于 Listing/PPC。
4. **跳到下一步**：把主要流量词拿到「关键词挖掘」拓词；把 ASIN 拿到「查流量来源」看自然/推荐/广告结构。
