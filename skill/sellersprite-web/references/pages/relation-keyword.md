# 关联流量（relation traffic）

## 1. 用途

输入父体/子体 ASIN，查看该 Listing 在亚马逊详情页关联流量位置曝光过的产品，以及这些关联带来的流量结构。

- 适合：看竞品的关联流量来源、相似/相关/广告关联商品、免费与付费关联占比；判断某个 ASIN 的流量是否依赖关联位。
- 不适合：查关键词搜索流量（用「关键词反查」/「查流量来源」）；查广告投放架构（用「广告洞察」）；查具体出单词（用「出单词反查」）。
- 数据来自卖家精灵网页与估算模型，不是 Amazon 官方数据。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/relation-keyword`
- 查询后页面标题形如 `<ASIN>|关联流量|卖家精灵`。
- 导航：工作台「运营推广」→ **关联流量**。
- 同组子导航：广告洞察 / 查流量来源 / 关联流量 / 出单词反查 / AI评论分析2.0。

## 3. 站点选择

- 查询栏有站点下拉，默认「美国站」；US 用 USD（页面价格显示 `$`）。
- 站点下拉实测包含：美国站、日本站、英国站、德国站、法国站、意大利、西班牙、加拿大、印度站、墨西哥、巴西站、澳洲站。
- 本页 US 已完整验证；CA 只确认站点控件含「加拿大」，未选择、未查询，CA 数据/币种未验证。

## 4. 页面结构

1. **子导航**：广告洞察 / 查流量来源 / 关联流量 / 出单词反查 / AI评论分析2.0 / 产品监控 / 关键词监控 / 店铺上新监控。
2. **查询栏**：站点下拉、ASIN 输入（最多 20 个，回车提交单个 ASIN，也可从 txt/Excel 按列粘贴）、`清除`、`立即查询`、`查询历史`。
3. **查询方式弹窗**：选择「使用全部变体对比」或「使用当前变体对比」；底部按钮显示两种方式的关联数。
4. **商品摘要**：ASIN、卖家、BSR、价格、评分/评分数、上架时间；快捷入口含广告洞察、出单词反查、查流量来源等。
5. **变体条**：当前 ASIN 及各变体的关联数，可切换变体。
6. **关联流量占比**：全部关联、免费关联、付费关联，含数量和百分比。
7. **结果过滤**：关联类型多选（看了又看、相似产品、看了还看、看了却买、捆绑销售、组合购买、更多相关、买了又买、品牌推荐、商品广告、四星产品、品牌广告）、`开始筛选`、`重置条件`、`复制ASIN`、`自定义品类`、`加入产品库`、`导出`。
8. **结果区**：`搜索结果数`、大图模式开关、排序（关联ASIN数/引流时间，升序/降序）、结果卡片或表格、分页。
9. **卡片字段**：产品图/标题/ASIN、FBA、卖家/品牌、BSR、销量、销售额、变体数、价格、评分/评分数、关联类型、关联数、引流时间。

## 5. 必填输入与可选筛选

- **ASIN**：必填；实测输入框支持最多 **20 个**父/子体 ASIN，回车提交单个 ASIN，也可从 txt/Excel 按列粘贴。
- **站点**：默认美国站。
- **查询方式**：`使用全部变体对比` 或 `使用当前变体对比`；本次选「当前变体」，结果数 721。
- **关联类型**：默认全选；可单选/多选后点 `开始筛选`。
- **排序**：关联ASIN数或引流时间，升序/降序。
- **大图模式**：默认勾选，结果以卡片展示；取消勾选可切换表格视图（本次未切换）。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v3/relation-keyword" --json`；确认标题含「关联流量」、站点是美国站。
2. 输入 1 个示例 ASIN（本次用 `B0FD3BR3RD`），点 `立即查询`。
3. 弹窗选择查询方式：本次选 `用当前变体查询`（按钮显示 721）；不要同时点全部变体和当前变体。
4. 等结果加载：先读商品摘要、变体条、关联流量占比，再读 `搜索结果数` 和分页。
5. 读结果：`read-table.js` 可读隐藏的 Element UI 表格（source=`el-table-store`），得到表头和 50 行数据；大图模式下的卡片也可用 `bsk observe` 读首卡。
6. 需要筛选时选关联类型后点 `开始筛选`，再重新读 `搜索结果数`/total。
7. 不要点 `导出`、`加入产品库`、`复制ASIN`；本次只读。
8. 结束 `bsk close`。

## 10. 空态与页面坑

- **查询方式弹窗**：输入 ASIN 后点 `立即查询` 会先弹「选择关联流量查询方式」；必须二选一，不能直接读结果。
- **两种查询方式结果不同**：全部变体 730、当前变体 721（本次实测）；报告必须写清用的哪一种。
- **三个数不要混**：`搜索结果数 721`、`全部关联 798`、变体总关联数 730 的口径不同；不要把 798 当结果条数。
- **大图模式默认开启**：结果看起来是卡片，但 `read-table.js` 仍能读 `el-table-store`；如果读不到，先取消大图模式或改用 `bsk observe` 读 `.relation-content-card`。
- **关联类型默认全选**：筛选后必须点 `开始筛选`；筛选条件不一定写进 URL，读页面回显。
- **结果陈旧**：切换变体/关联类型后旧卡片仍可能可见；先核对 `搜索结果数` 和首卡 ASIN 再报数。
- **隐私**：页面会显示卖家名称/地址等公开信息；报告不需要记录卖家名、地址、联系方式。
- 本次未触发空态，未验证空态文案；不要凭猜测写。

## 12. 典型配方

1. **看竞品关联结构**：输入竞品 ASIN → 选当前变体 → 读免费/付费占比 → 按关联类型筛选 → 看高关联数商品。
2. **找相似产品**：只勾选「相似产品」→ `开始筛选` → 读关联 ASIN 列表。
3. **找广告关联**：勾选「商品广告」「品牌广告」「四星产品」→ 看付费关联商品。
4. **对比变体**：在变体条切换 ASIN → 重新读关联数和首卡。
5. **后续分析**：把关联 ASIN 拿到「广告洞察」看广告架构，或「出单词反查」找出单词；本页不写广告、不导出。
