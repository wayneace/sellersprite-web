# 销量预测（sales estimator）

## 1. 用途

免费工具：按 BSR 排名或子 ASIN 预测产品销量。

- **BSR销量预测**：输入 BSR 数值，估算该排名对应的日销量/月销量。
- **ASIN销量预测**：输入子 ASIN，查看该产品逐月预测销量、预测销售额和平均单价。
- 适合：快速估算某个 ASIN 或某个 BSR 档位的销量规模；给选品/利润测算提供参考。
- 不适合：替代真实销售数据；查关键词/流量（用关键词反查、查流量来源）；批量预测多个 ASIN（本页一次一个）。
- 数据来自卖家精灵估算模型，不是 Amazon 官方数据。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v2/tools/sales-estimator`
- 查询后 URL 形如：`https://www.sellersprite.com/v2/tools/sales-estimator?market=US&asin=<ASIN>`
- 导航：工作台「免费工具」→ **销量预测**。
- 这是 **v2 页面**；有 `BSR销量预测` / `ASIN销量预测` 两个模式。

## 3. 站点选择

- 表单有站点按钮，默认「美国」；US 用 USD（金额显示 `$`）。
- 站点菜单实测包含：美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度、墨西哥等。
- 本页 US 已完整验证；CA 只确认站点控件含「加拿大」，未选择、未预测，CA 数据/币种未验证。

## 4. 页面结构

1. **模式切换**：`BSR销量预测` / `ASIN销量预测`。
2. **查询表单**：站点按钮、输入框、`预测销量`、`查询历史`。
3. **商品摘要**（ASIN 模式）：标题、ASIN、品牌、所属类目、评分数/评分、上架时间；快捷入口查竞品/关键词反查/出单词反查/广告洞察/查流量来源。
4. **结果区**：一张转置表（月份为列，指标为行），上方有 `导出`。
5. **结果指标**：`预测月销量`、`预测月销售额`、`平均单价`。
6. **说明**：BSR 模式输入 BSR 数值；ASIN 模式输入子 ASIN；工具免费。

## 5. 必填输入与可选筛选

- **模式**：默认 `BSR销量预测`；本次切到 `ASIN销量预测`。
- **ASIN**：ASIN 模式下必填，单个子 ASIN；placeholder `输入子ASIN，如：B071NDT5Q3`。
- **BSR**：BSR 模式下输入 BSR 数值（本次未验证 BSR 模式结果）。
- **站点**：默认美国。
- **查询历史**：可看历史查询（本次未打开）。
- 没有分页/排序控件；结果固定展示一段月份区间。

## 6. 操作流程

1. `bsk open "https://www.sellersprite.com/v2/tools/sales-estimator" --json`；确认标题含「销量预测」。
2. 点 `ASIN销量预测` 标签。
3. 输入示例子 ASIN `B071NDT5Q3`（页面 placeholder 的示例），点 `预测销量` 一次。
4. 等商品摘要和结果表出现；读商品摘要、表头和三行指标。
5. 结果表是转置表，用 `bsk observe` 读 VOM 最稳；`bsk extract table` 会因多表歧义/转置结构读不全。
6. 不要点 `导出`；本次只读。
7. 结束 `bsk close`。

## 7. 结果表关键列

表头：`月份`、`预测月销量`、`预测月销售额`、`平均单价`。

结果是**转置表**：月份作为列，指标作为行。实测（2026-11-14，US，ASIN `B071NDT5Q3`）：

- 月份：`2025-10` 到 `2026-11`，共 14 个月。
- 预测月销量：`291, 373, 343, 200, 153, 268, 144, 142, 149, 198, 296, 272, 266, 151`
- 预测月销售额：`$11,513, $14,916, $13,717, $7,998, $6,118, $10,717, $5,759, $5,679, $5,959, $7,918, $11,837, $10,877, $10,637, $6,038`
- 平均单价：`$39.55`（首月），其余 `$39.99`

商品摘要实测：ASIN `B071NDT5Q3`、品牌 `Emerson`、类目 `Electronics`、评分数 `7,827(4.2)`、上架时间 `2017-06-27`。

## 8. 排序、分页、每页条数

- 没有分页、排序或每页条数控件。
- 结果固定为 14 个月（本次 `2025-10` 到 `2026-11`）；月份范围由页面模型决定，不要按系统日期猜。
- 表是转置结构，不能按常规行表读取；按“指标行 × 月份列”读。

## 9. 导出

- 结果区有 `导出` 按钮；本次验证**没有点击**。
- 导出是下载/有副作用的操作，需要时按 `workflow.md` 的导出规则单独确认，只提交一次。

## 10. 空态与页面坑

- **两个模式**：`BSR销量预测` 输入 BSR 数值，`ASIN销量预测` 输入子 ASIN；不要把 ASIN 填进 BSR 模式。
- **v2 页面**：布局与 v3 不同；输入是标准 textbox，本次 `bsk fill` 正常。
- **转置表**：`bsk extract table` 会报 `Multiple containers found`；指定第一个 target 只得到合并列名、0 行。不要用它读数据，改用 `bsk observe` 读 VOM。
- **结果不是表格行**：月份是列，销量/销售额/单价是行；报告写清“月份→销量”的对应关系。
- **估算数据**：页面是预测模型，不是实际销量；报告必须加免责声明。
- **免费不等于无限**：仍不要重复跑同一查询；本页一次一个 ASIN。
- **导出**：有 `导出` 按钮；本次未点。
- 本次未触发空态，未验证空态文案。

## 12. 典型配方

1. **估算 ASIN 销量**：ASIN 模式 → 输入子 ASIN → 读 14 个月预测销量/销售额/均价。
2. **看季节性**：比较 2025-10 到 2026-11 的销量峰谷，找旺季月份。
3. **估算销售额**：读预测月销售额行，和利润计算器结合算毛利。
4. **按 BSR 估算**：切 BSR 模式 → 输入 BSR 数值 → 读日/月销量（本次未验证）。
5. **后续分析**：把 ASIN 拿到利润计算器/选产品；本页不导出。
