# 字段词典（fields）

按页面可见的中文列名整理。单位以页面为准；同名指标在不同页面可能不是同一种算法，跨页对比前先看这里的「易错点」。

## 通用

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| BSR | 亚马逊类目畅销排名 | 名次，越小越好 | 不同类目的 BSR 不可直接比较；主类目/子类目要看清 |
| LQS | Listing 质量分（卖家精灵评分） | 分 | 不是销量或转化率 |
| 评论数 / 评分数 | 商品获得的评分次数 | 个 | **不是文字评论条数**；页面通常写「评分数」 |
| 评分 | 星级 | 0–5 | 不是评论数 |
| 变体 | 父体/子体关系与变体数 | 个 | 父体销量和子体销量不是一回事 |
| FBA | 配送方式或 FBA 费用 | 是/否；货币随站点 | 费用列不是售价 |
| 卖家类型 | AMZ（亚马逊自营）/ FBA / FBM | 枚举 | 与「配送方式」区分 |
| 上架时间 | Keepa 首次看到价格或 BSR 的日期 | 日期 | 不是 exact 上架日；`availableDate` 语义 |
| 数据月份 | 页面月份选择器的值 | 月份或「最近30天」 | 不要按系统日期猜；最近30天 ≠ 自然月 |

## 关键词

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 月搜索量 | 一个自然月内该词的亚马逊搜索次数 | 次/月 | 不是当天搜索量；月初更新上月数据 |
| 月购买量 | 搜索该词后一个自然月内的购买次数 | 次/月 | 一单买多个相关商品只计一次 |
| 购买率 | 月购买量 / 月搜索量 | % | 不要和商品转化率比较 |
| 展示量 | 该词结果页**所有 ASIN** 一个月的总曝光 | 次/月 | 不是单个 ASIN 的曝光 |
| 点击量 | 该词结果页一个月的总点击 | 次/月 | 不是单个 ASIN 的点击 |
| SPR | 8 天内维持该词首页所需的销量估算 | 件/8天 | 不是月销量；越高越难 |
| 标题密度 | 首页（不含广告）标题包含该词的商品数 | 个 | 不是百分比 |
| 商品数 | 该词在全类目下的相关商品数 | 个 | 不是本次报告的样本数 |
| 需供比 | 月搜索量 / 商品数 | 比值 | 越高代表需求相对供给越强；不要倒过来 |
| 广告竞品数 | 近 7 天进入前 3 页广告位的商品数 | 个 | 不是广告位数量 |
| Top3 点击占比 | 点击前 3 的 ASIN 合计点击份额 | % | 和「Top3 转化占比」分母不同，不要混用 |
| Top3 转化占比 | 点击前 3 的 ASIN 合计转化份额 | % | 不是点击份额 |
| PPC 竞价 | 建议竞价 | 货币随站点 | 不是实际 CPC；US=USD，CA=CAD |
| 流量占比 | 该词带来的流量占商品全部流量词的比例 | % | 只出现在反查类页面 |
| 自然搜索词 | 商品在自然结果前 3 页出现的词 | 个数 | 不是只有第 1 页 |
| 广告词 | 商品出现在 SP/SB/SBV 广告位的词 | 个数 | 三种广告类型要分开看 |

## 市场与 ABA

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 月总销量 | 细分市场样本商品的月销量合计 | 件/月 | 不是单个 ASIN 销量；样本由「Listing样本数量」决定 |
| 月均销量 | 月总销量 / 样本商品数 | 件/月 | 不是头部商品均值 |
| 月均销售额 | 头部商品月均销售额 | 货币随站点 | 列名有「头部商品」限定，不是全市场 |
| 平均 BSR | 样本商品的平均 BSR | 名次 | 不同类目不可直接比 |
| 商品集中度 / 品牌集中度 / 卖家集中度 | Top N 商品/品牌/卖家的销量或销售额占比 | % | 看页面是 Top3/Top10/Top20 哪一档 |
| A+ 数量占比 | 样本中带 A+ 内容的商品占比 | % | 不是转化率 |
| FBA / FBM / AMZ 占比 | 配送方式/自营占比 | % | 三者口径不同，不要相加当 100% |
| 卖家所属地占比 | 样本中各国卖家占比 | % | 与「卖家类型」不是一回事 |
| ABA 排名 | 亚马逊 Brand Analytics 搜索频率排名 | 名次 | 同频词会显示相同排名并按字母排序 |
| 搜索增长率 | ABA 搜索量/排名的增长 | % | 页面可能用排名变化率，不是搜索量增长率 |
| 点击共享 / 转化共享 | Top3 ASIN 的点击/转化份额 | % | 点击份额和转化份额分母不同 |
| 点击前三点击集中度 / 转化集中度 | 点击前三 ASIN 合计点击/转化占比 | % | 不是单个 ASIN 的转化率 |

## 转化与竞价

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 搜索转化率 | 购买量 / 搜索量 | % | 不是点击转化率 |
| 点击转化率 | 购买量 / 点击量 | % | 与搜索转化率分母不同 |
| CPA | 每次购买的成本估算 | 货币随站点 | 不是 CPC；有精准/词组/广泛三档 |
| ACOS | 广告花费 / 广告销售额 | % | 页面 item 里是小数；41.48% 写作 0.4148 |
| 广告预算 | 维持该词广告的建议日预算 | 货币随站点 | 是估算，不是账户实际预算 |
| 产品均价 | 该词结果页商品的平均价格 | 货币随站点 | 有 min/max/value，报告用 value |
| 建议竞价 | 亚马逊建议的 PPC 出价 | 货币随站点 | 不是实际 CPC |
| 竞价区间 | 建议竞价的最低–最高范围 | 货币随站点 | 六种策略可能显示同一个区间 |
| 任务状态 | 实时查竞价的异步任务状态 | 查询中/已完成等 | 实测 2=查询中、3=已完成；其他状态未映射 |
| 流量占比（对比/拓展） | 该词在某 ASIN 或词库中的流量占比 | % | 不同页面的分母不同，不要跨页直接比 |
| 有效竞品数 | 去重/有效后的竞品 ASIN 数 | 个 | 不一定等于输入数量 |
| 相关 ASIN | 拓展流量词里的变体/相关 ASIN 列表 | 列表 | 不是结果行本身 |

## 广告与关联

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 广告组 / 广告活动 | 卖家精灵展示的广告组/活动编号 | 文本 | 是竞品广告架构编号，不是投放词；编号可能被页面脱敏/缩写 |
| 广告类型 | SP / SBV 等 | 枚举 | 广告洞察只含 SP、SBV 的关键词投放，不含商品投放、SB、SD |
| 投放小组数 | 汇总句里的广告组数量 | 个 | 不等于广告活动数；同一活动可有多个组 |
| 关联类型 | 看了又看/相似产品/看了还看/看了却买/捆绑销售/组合购买/更多相关/买了又买/品牌推荐/商品广告/四星产品/品牌广告 | 枚举 | 同一商品可出现在多个关联类型，报告要写类型 |
| 关联数 | 某关联类型下关联 ASIN 的次数/数量 | 个 | 不是搜索结果条数；同一 ASIN 可能重复出现 |
| 免费关联 / 付费关联 | 关联流量的免费/广告占比 | % | 与「搜索结果数」分母不同，不能相加当结果数 |
| 关联流量占比 | 关联来源占全部流量的比例 | % | 不同页面分母不同，不跨页直接比 |
| 引流时间 | 关联商品在详情页曝光的日期 | 日期 | 不是商品上架时间 |
| 搜索结果数 | 当前变体/全部变体查询命中的结果条数 | 条 | 与「全部关联」合计不是一个数；看查询方式 |
| 支持变体查询 | 用全部变体或当前变体查询 | 枚举 | 两种方式结果数不同，报告要写清 |

## 出单词与预测

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 出单词 / 关键词 | ASIN 进入过 ABA 点击前 3 的关键词 | 文本 | 不是广告投放词；未进前 3 不收录 |
| 转化效果 | 转化优质词/转化平稳词等 | 枚举 | 页面分类，不是转化率数值 |
| 周搜索量 | ABA 周搜索量 | 次/周 | 不是月搜索量；数据周看周选择器 |
| 排名 / 周变化量 / 周变化率 | ABA 排名及周变化 | 名次 / 名次 / % | 排名趋势是三列，不要只读一个 |
| 点击占比 / 转化占比 | 该词点击/转化份额 | % | 点击份额和转化份额分母不同 |
| ABA 集中度 | 头部 ASIN 的集中程度 | % | 可能显示两个值（点击/转化），看页面 |
| 点击前三 ASIN | 该词点击前 3 的 ASIN | 列表 | 不是全部竞品；是点击前三 |
| 预测月销量 | 模型预测的月销量 | 件/月 | 是估算，不是实际销量 |
| 预测月销售额 | 模型预测的月销售额 | 货币/月 | 与预测月销量×均价可能因四舍五入有差异 |
| 平均单价 | 预测期平均售价 | 货币 | 首月可能与其他月不同 |
| BSR销量预测 / ASIN销量预测 | 两种预测模式 | 枚举 | BSR 模式输入排名，ASIN 模式输入子 ASIN，不能混填 |

## 利润计算

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 商品售价 / 商品运费 | 买家支付的售价/运费 | 货币随站点（US 实测 USD） | 售价不是采购价；运费是向买家收取的 |
| 采购成本 | 采购成本 | 货币随站点（US 实测 CNY） | 页面用人民币，不是 USD；报告写清币种 |
| 头程运费 | 从国内到 FBA 的运费 | 货币随站点（US 实测 CNY） | 需要选海运/空运/快递；填完要失焦提交 |
| 其他成本 | 其他商品成本 | 货币随站点（US 实测 CNY） | 不含广告/售后，另有字段 |
| 销售佣金率 / 销售佣金 | 亚马逊佣金率/金额 | % / 货币随站点 | 由商品类别带出；不选类别时为 0 |
| FBA运费 | 亚马逊配送费 | 货币随站点（US 实测 USD） | 不是直接输入；通过包装尺寸/重量计算器得出 |
| 收入小计 / 成本小计 | 收入/成本合计 | 货币 | 收入小计不等于净利润 |
| 净利润 / 净利率 / ROI | 利润、利润率、投资回报率 | 货币 / % / 比值 | 净利率分母是收入；ROI 分母是成本 |
| 1月-9月 / 10月-12月 | 两档仓储费用口径 | 货币 | 两档可能不同；报告要写用哪档 |
| 汇率 (USD/CNY) | 美元兑人民币汇率（US 实测） | 比值 | 改汇率会改变折算结果；本次未更新 |

## AI 报告

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 消耗次数 | 生成报告按钮标注的扣减次数 | 次 | 生成前先记录；失败/超时不重试，避免重复扣 |
| 报告状态 | 生成中/已完成/失败等 | 枚举 | 以页面实际状态为准，不按时间猜 |
| 创建时间 / 过期时间 | 报告生成/过期时间 | 日期时间 | 有效期以页面为准；多数 AI 页 10 天，KRT 为 30 天 |
| 报告有效期 | 报告可查看/下载的期限 | 天 | 过期不要重新生成，先告诉用户 |
| 报告模块 | 报告左侧/正文模块标题 | 列表 | 只读模块标题，不抄全文 |
| 报告卡 | 最近报告列表里的卡片 | 列表 | 卡片有删除入口，删除后分享链接失效 |
| 剩余额度 | 账号剩余 AI 次数 | 次 | 账号数据，报告/文档不记录具体数字 |
| 词库关键词数 | KRT 前置词库的关键词数量 | 个 | 少于 50 个页面提示打标效果有限；空词库不能生成 |

## 商品

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 父体销量 | 父体下所有卖家/变体的合计销量 | 件/月 | 不是单个子体 ASIN 的销量 |
| 子体销量 | 子体 ASIN 在亚马逊搜索页显示的销量标识 | 件/月 | 口径与父体销量不同，不能直接相加 |
| 销售额 | 区间内父体级销售额 | 货币随站点 | 不是子体销售额；看列名区分 |
| 毛利率 | (售价 − 佣金 − FBA 费用) / 售价 的估算 | % | 不是采购毛利；未含头程和广告 |
| FBA 费用 | 按包装尺寸/重量估算的亚马逊配送费 | 货币随站点 | 不含头程；包装尺寸不是商品尺寸 |
| 留评率 | 月新增评分数 / 月销量 | % | 不是评分星级 |
| 上架时间 | Keepa 首次见价或见 BSR 的日期 | 日期 | 不是精确上架日；上架天数由此推算 |
| 变体范围 | 「唯一畅销变体」或「展示所有变体」 | 枚举 | 同一筛选下两种范围行数可能差很多 |
| 低价商品 | 是否包含低价/特殊商品 | 开关 | 打开会改变商品范围，报告要写 |
| 卖家所属地 | 卖家注册地 | 国家/地区 | 亚马逊自营与第三方要分开看 |

## 流量

| 字段 | 含义 | 单位/取值 | 易错点 |
|---|---|---|---|
| 自然搜索 | 商品在自然结果前 3 页出现的词 | 个数 | 不是自然订单占比 |
| AC 推荐词 | 带 Amazon's Choice 标识或推荐位的词 | 个数 | 不是自然搜索词 |
| ER 推荐词 | Editorial Recommendations 位的词 | 个数 | 与 AC 不同 |
| 4 星推荐词 | 4 星以上样式位的词 | 个数 | 与 HR 不同 |
| HR 推荐词 | Highly Rated 广告位（属 PPC）的词 | 个数 | 不是自然推荐 |
| SP 广告词 | Sponsored Products 广告位出现的词 | 个数 | 不含 SB/SBV |
| SB 广告词 | Sponsored Brands 广告位出现的词 | 个数 | 与 SP 分开 |
| SBV 广告词 | Sponsored Brands Video 广告位出现的词 | 个数 | 与 SB 分开 |
| 全部流量词 | 推荐 + 自然 + 广告词合并去重后的总数 | 个数 | 不等于各来源相加（来源会重叠） |
| 自然流量占比 | 自然搜索词 / 全部流量词 × 100% | % | 分母是全部流量词，不是各来源计数之和 |
