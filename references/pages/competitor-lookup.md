# 竞品分析（查竞品）

## 1. 用途

回答「谁在和我抢同一个词/同一批买家」：给定 ASIN、关键词、品牌、卖家或类目，列出竞品商品及其销量、销售额、价格、BSR、评分、FBA 等核心数据。

- 适合：找一个 ASIN 的直接竞品；一个关键词下的头部商品；一个品牌/卖家的在售商品；一个类目的销量榜。
- 不适合：要市场级汇总（集中度、新品占比、退货率）→ 用「选市场」；要关键词需求/竞争指标 → 用关键词类页面。

## 2. URL 与导航

- URL：`https://www.sellersprite.com/v3/competitor-lookup`
- 导航：工作台「产品」→ 大数据选品 → **查竞品**；页面子导航第一项也是「查竞品」。
- 查询后 URL 会带上参数，例如
  `?market=US&monthName=bsr_sales_nearly&asins=[]&keywords=yoga%20mat&page=1&nodeIdPaths=[]&symbolFlag=true&size=60&order[field]=amz_unit&order[desc]=true&lowPrice=N&salesGrowthType=30d`
- 查询结果页标题变为「查询结果|查竞品|卖家精灵」。

## 3. 站点选择

- 站点下拉在查询栏最左侧，显示「美国站」/「加拿大站」。
- US 用 USD（页面显示 `$`），CA 用 CAD（页面显示 `C$`）；销售额、价格、FBA、买家运费都随站点货币。
- 切换站点后会重新查询；必须重新读 total、币种和结果，不能沿用切换前的数据。详见 [sites.md](../sites.md)。
- CA 只确认了站点控件可切，未逐页验证 CA 数据/币种。

## 4. 页面结构

1. **子导航**：查竞品 / 选产品 / 选市场 / 关键词选品 / ABA数据选品 / 外观专利 / 全球商标库 / 产品库 / 自定义品类。
2. **查询栏**：电商平台（亚马逊 / TikTok）、选择站点、月份（默认「最近30天」）、选择类目、关键词、品牌、卖家、父(子)体 ASIN 或产品链接、立即查询。
3. **结果区**：搜索结果数、展示所有变体、列表/大图视图、自定义列、导出/导出明细、表格。
4. **分页区**：每页条数、页码、总数。
5. **右上工具**：自定义品类、我的导出、查询历史。

## 5. 必填输入与可选筛选

五种入口**至少填一个**，可以组合：

| 入口 | 页面标签 | 适用场景 |
|---|---|---|
| 关键词 | 关键词 如:flashlight | 不知道具体 ASIN，先看这个词下的竞品 |
| 品牌 | 品牌 如:Anker | 看某品牌在售商品 |
| 卖家 | 卖家 如:AnkerDirect | 看某卖家的商品结构 |
| ASIN | 父(子)体ASIN或产品链接，如 B00FLYWNYQ | 已知竞品，找同类 |
| 类目 | 选择类目 | 看一个类目的销量榜 |

- 月份默认「最近30天」（`bsr_sales_nearly`），也可选自然月；数据月份以页面下拉为准。
- 「展示所有变体」复选框默认勾选；它对应 URL 的 `symbolFlag=true`。**该字段在竞品页的确切语义未单独验证，保持页面默认，不要为了「少几行」随意改。**
- 页面当前版本**没有看到独立的「低价」开关**；URL 里 `lowPrice=N` 是默认值，不要手改 URL 绕过页面。
- 组合入口（如关键词 + 品牌 + 卖家）会取交集，先用一个入口跑通再加条件。

## 6. 操作流程

1. 打开页面，确认站点和月份。
2. 在对应输入框填值（关键词/品牌/卖家/ASIN），或用「选择类目」选类目。
3. 点「立即查询」；等待结果区出现「搜索结果数」和表格。
4. 动作后重新 `observe` 或读状态；点击返回成功不等于查询生效。
5. 需要排序/换页时，先改下拉再等表格刷新，然后重新读表。
6. 读取优先 `<skill-dir>/scripts/read-table.js`（本页 `bsk extract table` 对 div 表格读不出行，见第 10 节）。

## 7. 结果表关键列

实测表头（2026-11-12，US，关键词 `yoga mat`）：

`#`、`产品信息`、`数据解释`、`大类BSR`、`销量趋势(父)`、`销量趋势(子)`、`销量(父)`、`增长率`、`销售额`、`子体销量`、`子体销售额`、`变体数`、`价格`、`Q&A`、`评分数`、`月新增`、`评分`、`留评率`、`FBA`、`毛利率`、`上架时间`、`配送`、`买家运费`、`操作`。

- 产品信息列包含：图片、标题、ASIN、父 ASIN（页面写作「父ASIN : …」）、品牌、类目、卖家、卖家所属地、配送方式、Coupon、尺寸/重量等，以及 A+/视频/BS/AC/NR 等标识。父体/子体 ASIN 要分清。
- 「自定义列」可以增减列（如 LQS、卖家、所属地、尺寸、Coupon）；不同账号/列设置下可见列会不同，以页面实际表头为准。
- 操作列的图标可打开「销量趋势」抽屉和「历史趋势」（Keepa）抽屉；抽屉里是图表和月度序列，不改变当前表格。
- 字段口径见 [fields.md](../fields.md)：`销量(父)` 是父体级，`子体销量` 是子体口径，不能直接对比。

## 8. 排序、分页、每页条数

- 默认排序下拉显示「子体销量 / 降序」，URL 为 `order[field]=amz_unit&order[desc]=true`。
- 每页条数默认 **60**（页面可选值见下拉）；低于 60 的请求接口可能返回空，按页面选项来。
- 页码在 URL 的 `page` 参数；翻页后重新读表，不要沿用上一页 items。
- 页面标题区显示「搜索结果数: 5,000+」，分页组件实测 `total=2000`（US / yoga mat / 60 条/页）。两者口径不同：**报告写分页组件的 total 并备注页面显示值**，不要自己相加。
- 旧知识：前端最多暴露前 5,000 条匹配；超过后分页会截断。以页面分页实际为准。

## 9. 导出

- 结果区有「导出」和「导出明细」两个按钮；导出是异步任务。
- 只提交一次；到右上「我的导出」看任务状态；文件出现后用 `bsk download` 保存到用户指定路径。
- 本页验证**没有提交导出任务**，只确认了按钮和入口存在。

## 10. 空态与页面坑

- 关键词无结果时，结果区显示「很抱歉，暂无结果！」，并列出可能原因（ASIN 输入有误；ASIN 创建不久或销量太少，没有达到该类目销量前 50 万），同时推荐插件查询。
- 这个空态**不是** `.el-table__empty-text`：`read-table.js` 会返回 `rowCount=0`、`total=0`、`empty=false`。判断空结果要看 `total` 和页面正文，不要只看 `empty`。
- `bsk extract table` 在本页会报 `Multiple containers found`；带 `--selector ".el-table"` 又会报 `Target is not an HTML or ARIA table/grid`；用 `extract discover` 拿到的 target 虽能返回列定义，但 **rows 为 0**（div 表格）。本页读取用 `<skill-dir>/scripts/read-table.js`。
- 输入关键词后回车会自动提交；想改条件再查时，先确认输入框回显的是新值。
- 结果表里同一个父体的变体可能合并/展开，行数与「展示所有变体」的设置有关。

## 11. 验证清单

报数据前逐项核对：

- [ ] URL 是 `/v3/competitor-lookup` 且带本次查询参数。
- [ ] 站点是 US 或 CA，币种与站点一致。
- [ ] 月份是页面下拉显示的值（默认「最近30天」）。
- [ ] 查询条件与输入框回显一致（关键词/品牌/卖家/ASIN/类目）。
- [ ] `total`（分页组件）和「搜索结果数」都记录，差异写进备注。
- [ ] 实际读取行数、当前页、每页条数。
- [ ] 表头与文档一致；用了「自定义列」要说明。
- [ ] 首行 ASIN 可作为后续关键词反查/流量来源的样例。

## 12. 典型配方

1. **ASIN → 竞品**：在「父(子)体ASIN或产品链接」填一个 ASIN → 立即查询 → 读前 60 行 → 按销量或销售额判断直接竞品。
2. **关键词 → 竞品**：关键词填 `yoga mat` → 最近30天 → 读表；再用「自定义列」加上卖家/所属地/FBA，筛掉不符合的对手。
3. **品牌/卖家 → 商品结构**：品牌填品牌名（或卖家填卖家名）→ 查询 → 看价格带、评分、变体数分布。
4. **竞品 → 深筛**：把这里发现的 ASIN 拿到「选产品」做价格/销量/评论条件筛选；把 ASIN 拿到「关键词反查」「查流量来源」看流量结构。
